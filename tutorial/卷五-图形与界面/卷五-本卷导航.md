# 卷五导航 · 图形与界面

> [!abstract] 本卷定位
> 把数学算出来的坐标**真的画到手机屏幕上**，并让菜单能被手指点到。
> **本卷产出 `overlay`：一个完整的原生覆盖层框架。**

## 学完你能做什么

- [ ] 能说出图形管线七个阶段，知道本项目从哪一步开始
- [ ] 会写 Vulkan 初始化，知道每个结构体必须填 `sType`
- [ ] 知道本项目的透明靠"图层 RGBA_8888 + 清屏 alpha=0"（不是靠 compositeAlpha）
- [ ] 会用 `dlopen` 动态加载 Vulkan，缺库时优雅降级
- [ ] 会写 ImGui 绘制（`AddRect`/`AddLine`/`AddText`）
- [ ] **能创建透明悬浮图层，并在 `dumpsys` 里看到它**
- [ ] 中文能正常显示
- [ ] 菜单能被点，菜单外能穿透到游戏
- [ ] 稳定 60fps，有性能面板
- [ ] **有一个完整的覆盖层框架**

## 最容易卡住的四个地方

| 卡点 | 章节 | 建议 |
|---|---|---|
| **Vulkan 初始化代码太长** | 58 | 大部分是模板，抄一遍理解结构即可，不用背 |
| **符号名不匹配（版本差异）** | 65、66 | 用"按版本优先+失败全试"；先跑符号侦察器确认 |
| **悬浮窗黑底** | 59 | 检查图层格式是否 RGBA_8888、清屏色 alpha 是否为 0 |
| **触摸失灵/菜单点不到** | 71 | 用 `getevent -l` 确认事件；检查是否独占未释放 |

> [!warning] 开发触摸拦截前先看这个
> 如果程序崩溃时没释放 `EVIOCGRAB`，**设备触摸会完全失效**。
> 应急：`adb shell stop && adb shell start`，或 `adb reboot`。
> 见 [[附录C-排错手册]] 的"应急：触摸失灵"。

> [!tip] 本卷的学习方法
> 本卷的难点**不在算法，在环境**。
> 遇到问题先在附录 C 里搜症状，90% 都有人踩过。
> 另外：Vulkan 的初始化代码写一次就够，之后是复制粘贴——
> 把精力放在"图层属性"和"触摸"上，那才是本项目与众不同的地方。

## 本卷综合练习

**目标**：做出能用的覆盖层。

要求：
1. 透明图层 + ImGui 菜单 + 中文显示
2. 性能面板显示 FPS、帧时、各段耗时
3. 触摸：菜单能点、菜单外穿透
4. `dumpsys SurfaceFlinger` 确认图层 z 值最高
5. 换一台不同 Android 版本的设备（或模拟器）验证兼容
6. 加"过录制"开关，用 `screencap` 验证是否生效

**验收**：6 项全过。做到这一步，你已经有了一个**完整的原生覆盖层框架**——
卷六只需往里加"读内存"，卷七加"解析数据"，卷八加"遮挡判定"。
