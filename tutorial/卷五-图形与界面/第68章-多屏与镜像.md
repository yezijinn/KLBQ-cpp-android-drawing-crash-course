# 第 68 章 · 多屏与镜像

> [!abstract] 本章目标
> 理解 Android 的多显示设备模型，学会用 `dumpsys display` 解析屏幕信息，
> 并知道投屏时覆盖层怎么跟着显示。

## 先看有哪些"屏幕"

Android 上不止一个显示设备：

| 类型 | layerStack | 说明 |
|---|---|---|
| 内置屏幕 | 0 | 手机本身的屏 |
| 外接（HDMI/DP） | 1+ | 有线投屏 |
| 虚拟屏（scrcpy/Vysor） | 2+ | 软件创建的 |
| 无线投屏 | 1+ | Miracast / Chromecast |

```bash
adb shell dumpsys display
```

输出（简化）：

```
DisplayDeviceInfo{"内置屏幕":
  uniqueId="local:0"
  mDisplayId=0
  layerStack=0
  displayWidth=1080
  displayHeight=2400
  rotation=0
  type=BUILT_IN
}

DisplayDeviceInfo{"HDMI 屏幕":
  uniqueId="local:1"
  mDisplayId=2
  layerStack=1
  displayWidth=1920
  displayHeight=1080
  rotation=0
  type=HDMI
}
```

关键字段：

| 字段 | 含义 |
|---|---|
| `uniqueId` | 唯一标识 |
| `mDisplayId` | 显示 ID |
| `layerStack` | **图层栈 ID**（决定图层显示在哪个屏） |
| `displayWidth/Height` | 分辨率 |
| `rotation` | 旋转（0/1/2/3） |
| `type` | BUILT_IN / HDMI / WIFI / VIRTUAL / OVERLAY |

## 图层的 layerStack

默认创建的图层 `layerStack = 0`，只在内置屏幕显示。

要让它显示到第二个屏幕：

```cpp
t.setLayerStack(sc, 1);
```

或者创建镜像（见下）。

## 三种多屏方案

| 方案 | 做法 | 适用场景 |
|---|---|---|
| **多图层** | 每个屏幕创建一个图层 | 各屏内容不同 |
| **镜像图层** | `createMirrorSurface` | 各屏内容相同 ★ |
| **虚拟显示** | `createVirtualDisplay` | 录屏、scrcpy |

本项目的"多屏镜像"用第二种。

## SurfaceControl::createMirrorSurface

Android 提供的镜像 API：

```cpp
sp<SurfaceControl> mirror = SurfaceControl::createMirror(
    sourceDisplayId,      // 要镜像哪个屏
    displayWidth,
    displayHeight
);
```

或者老式的：

```cpp
sp<SurfaceControl> mirror = client->createSurface(
    String8("MirrorRoot"), w, h, PIXEL_FORMAT_RGBA_8888,
    ISurfaceComposerClient::eFXSurfaceContainer,   // 容器类型
    nullptr);
// 然后把子图层 reparent 进去
```

**注意**：镜像 API 在不同版本差异很大，本项目做了多套适配（第 66 章的方法）。

## 本项目的实现思路

`ANativeWindowCreator::ProcessMirrorDisplay()`：

```
1. 每秒执行一次（避免频繁解析）
2. popen("dumpsys display") 抓输出
3. 解析出所有非 0 的 layerStack 及其分辨率
4. 对每个 layerStack：
   a. 如果还没有镜像，创建一个 MirrorRoot 容器
   b. 创建 MirrorSurface 指向它
   c. 计算缩放矩阵（源分辨率 → 目标分辨率）
   d. 设置变换矩阵和位置
5. 如果某个屏幕消失了，销毁对应镜像
```

## 解析 dumpsys 输出

```cpp
struct DisplayInfo {
    int    displayId;
    int    layerStack;
    int    width;
    int    height;
    int    rotation;
    std::string uniqueId;
    std::string type;
};

std::vector<DisplayInfo> ParseDisplays(const std::string &text) {
    std::vector<DisplayInfo> out;
    DisplayInfo cur{};
    bool inBlock = false;

    std::istringstream iss(text);
    std::string line;
    while (std::getline(iss, line)) {
        if (line.find("DisplayDeviceInfo{") != std::string::npos) {
            if (inBlock) out.push_back(cur);
            cur = {};
            inBlock = true;
            continue;
        }
        if (!inBlock) continue;

        auto grab = [&](const char *key, int &dst) {
            size_t p = line.find(key);
            if (p == std::string::npos) return;
            dst = atoi(line.c_str() + p + strlen(key));
        };
        grab("mDisplayId=", cur.displayId);
        grab("layerStack=", cur.layerStack);
        grab("displayWidth=", cur.width);
        grab("displayHeight=", cur.height);
        grab("rotation=", cur.rotation);

        if (line.find("uniqueId=") != std::string::npos) {
            size_t a = line.find('"');
            size_t b = line.find('"', a + 1);
            if (a != std::string::npos && b != std::string::npos)
                cur.uniqueId = line.substr(a + 1, b - a - 1);
        }
        if (line.find("type=") != std::string::npos) {
            size_t p = line.find("type=");
            cur.type = line.substr(p + 5);
            // 去掉尾部空白
            while (!cur.type.empty() && isspace(cur.type.back()))
                cur.type.pop_back();
        }
    }
    if (inBlock) out.push_back(cur);
    return out;
}
```

**要点**：
- `DisplayDeviceInfo{` 是块的开始
- 每个字段用 `find` + `atoi` 提取
- 遇到下一个块时保存上一个

## 缩放与位置计算

镜像时要把源分辨率适配到目标屏：

```cpp
// 源：内置屏 1080x2400
// 目标：HDMI 1920x1080

float scaleX = (float)targetW / (float)sourceW;
float scaleY = (float)targetH / (float)sourceH;

// 保持宽高比（避免拉伸）
float scale = std::min(scaleX, scaleY);

// 居中偏移
float offsetX = (targetW - sourceW * scale) * 0.5f;
float offsetY = (targetH - sourceH * scale) * 0.5f;

// 变换矩阵（Android 用 3x3，按 dsdx/dtdx/... 或 float[9]）
float matrix[9] = {
    scale, 0.0f,   offsetX,
    0.0f,  scale,  offsetY,
    0.0f,  0.0f,   1.0f
};
t.setMatrix(sc, matrix);
```

考虑旋转（rotation 1/3 时宽高互换）：

```cpp
if (rotation == 1 || rotation == 3) {
    std::swap(sourceW, sourceH);
    // 旋转 90/270 度的矩阵
}
```

## 为什么本项目要管多屏

场景：用户用 scrcpy 投屏到电脑上操作。

```
电脑屏幕 (scrcpy 窗口)
    ↑ 虚拟屏 layerStack=2
    ↑ 如果覆盖层只在 layerStack=0，投屏画面里就看不到它
```

**做了镜像之后，投屏画面里也能看到覆盖层。** 这是实用的功能。

## 性能考虑

解析 `dumpsys display` 是**启动一个进程**，很慢（几十毫秒）。

本项目：

```cpp
void screen_config() {
    static std::chrono::steady_clock::time_point lastTime{};
    const auto now = std::chrono::steady_clock::now();
    if (now - lastTime < std::chrono::milliseconds(250)) return;   // ★ 节流
    ...
    lastTime = now;
}
```

**250ms 节流一次**——即使每帧调用 `screen_config()`，
实际每秒最多执行 4 次。

> [!tip] 更好的做法
> 用 `DisplayManager` 的回调监听屏幕变化，而不是轮询。
> 但原生层没有公开回调，只能轮询或者用 Binder 监听（复杂）。
> 本项目选择了节流轮询——简单且够用。

## 动手：屏幕信息解析器

把上面的 `ParseDisplays` 补全，加上输出：

```cpp
int main(void) {
    FILE *fp = popen("dumpsys display", "r");
    if (!fp) { printf("popen 失败\n"); return 1; }

    std::string text;
    char buf[4096];
    while (fgets(buf, sizeof(buf), fp)) text += buf;
    pclose(fp);

    auto displays = ParseDisplays(text);
    printf("发现 %zu 个显示设备:\n", displays.size());
    for (auto &d : displays) {
        printf("  [%d] %-16s layerStack=%d  %dx%d  rot=%d  type=%s\n",
               d.displayId, d.uniqueId.c_str(), d.layerStack,
               d.width, d.height, d.rotation, d.type.c_str());
    }
    return 0;
}
```

## 常见问题

| 问题 | 原因 | 解法 |
|---|---|---|
| `dumpsys` 输出格式对不上 | 厂商定制 ROM 改了输出 | 做容错解析，找不到就跳过 |
| 镜像创建了但没内容 | 源 layerStack 不对 | 核对 `layerStack` 字段 |
| 镜像变形 | 没处理宽高比/旋转 | 用 min(scaleX,scaleY) + 旋转矩阵 |
| 投屏画面卡顿 | 每秒重建镜像 | 缓存，只在变化时重建 |
| 屏幕消失后残留 | 没销毁 | 对比列表，销毁消失的 |
