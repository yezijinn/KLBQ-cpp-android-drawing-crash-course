## 为什么单独做一份词汇表

读代码时最耗时的往往不是逻辑，而是**词汇**：

```c
// 每个词都认识，但连起来读不出意思
static inline void store_request_status(int status);
```

| 词 | 认识吗 | 在这个语境里 |
|---|---|---|
| `static` | 静态的 | 文件作用域（仅本编译单元可见） |
| `inline` | 内联的 | 建议编译期展开，避免函数调用开销 |
| `store` | 存储 | **写入**（不是"商店"） |
| `request` | 请求 | 一次驱动交互的请求对象 |

**技术英语的特点**：动词多、名词化多、缩写多。
本表专治这三个问题。

### 音标

用 `/ /` 括起，美式发音：

```
buffer  /ˈbʌfər/
         └┬──┘
       主重音在第一节
```

符号说明：

| 符号 | 含义 | 例词 |
|---|---|---|
| `ˈ` | 主重音 | `ˈbuffer` |
| `ˌ` | 次重音 | `ˌcoˈalesce` |
| `ː` | 长音 | `caːche` 中的 `aː` |
| `ə` | 弱读元音（schwa） | `bʌfər` 末尾的 `ər` |
| `ɜːr` | 卷舌长元音 | `wɜːrd` |

> [!note] 为什么要标音标
> 技术词汇的口音读错很常见，且会**影响记忆**——
> 你读错的音，和别人说的音对不上，听力就废了。
> 几个高频易错词：
>
> | 词 | 常见错读 | 正确 |
> |---|---|---|
> | `cache` | /kætʃ/（像 catch） | **/kæʃ/** |
> | `height` | /heɪt/ | **/haɪt/** |
> | `width` | /wɪdθ/ | **/wɪdθ/** |
> | `integer` | /ɪnˈteɡər/ | **/ˈɪntɪdʒər/** |
> | `determine` | /ˈdetərmaɪn/ | **/dɪˈtɜːrmɪn/** |
> | `parameter` | /ˈpærəmitər/ | **/pəˈræmɪtər/** |
> | `cache line` | — | **/kæʃ laɪn/** |

## 学习建议

### 优先级三层

技术词汇不必全背。按使用频率分三层：

| 层级 | 占比 | 举例 | 要求 |
|---|---|---|---|
| **第一层：必须条件反射** | ~120 词 | `pointer` `buffer` `allocate` `size` `offset` `inline` `static` | 看到就懂，不用想 |
| **第二层：认识即可** | ~500 词 | `coalesce` `sparse` `granularity` `topology` | 看到能反应出大意 |
| **第三层：查得到就行** | ~470 词 | 特定库的专有名词 | 用本表查 |

**第一层的 120 词集中在 [[附录K4-工程与工具词汇]] 的"高频通用词"一节**，建议优先掌握。

### 三种读法

| 场景 | 怎么用 |
|---|---|
| **读代码时遇到生词** | Ctrl+F 查本册，看例句 + 解析 |
| **系统学习** | 每学完一卷，读对应册，把该卷高频词过一遍 |
| **写作/注释** | 查准确用词，避免中式英语（如 "open the lock" 应为 `acquire the lock`） |

### 从"认识"到"会用"

> [!tip] 技术英语的三个跃迁
> **跃迁 1：认识名词**（`buffer`、`pointer`）
> → 能读懂变量名
>
> **跃迁 2：认识动词**（`allocate`、`resolve`、`dispatch`）
> → 能读懂函数名和注释。**动词是最关键的一层**——
> 技术文档的信息量主要在动词上。
>
> **跃迁 3：认识搭配**（`acquire a lock`、`resolve a symbol`、`cast to type`）
> → 能写地道的注释和文档。这个层次靠积累，本表每条都标了搭配。

## 一个实用的练习

打开项目的 `driver.h`（1300 行，含大量英文注释），
用本表查遇到的生词，读完一遍你会发现：

**之前"看不懂"的代码，其实 80% 的生词都在第一层。**

```c
// 试试读这一段（driver.h:973-984）
inline void IoCommitAndWait()
{
    req->kernel = true;

    // 等内核完成
    while (!req->user)
    {
        asm volatile("yield");
    }
    // 消费完成标志
    req->user = false;
}
```

词表对照：

| 词 | 音标 | 义 |
|---|---|---|
| `commit` | /kəˈmɪt/ | 提交 |
| `wait` | /weɪt/ | 等待 |
| `kernel` | /ˈkɜːrnl/ | 内核 |
| `user` | /ˈjuːzər/ | 用户 |
| `consume` | /kənˈsuːm/ | 消费（取走并清除） |
| `flag` | /flæɡ/ | 标志 |
| `yield` | /jiːld/ | 让出（CPU） |
| `volatile` | /ˈvɑːlətl/ | 易变的（禁止优化） |

**八个词全认识，这段代码就完全读懂了**——它的逻辑就是"置标志、等待、清标志"。
