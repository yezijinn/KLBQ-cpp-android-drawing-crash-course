# 第 26 章 · 浮点数与 IEEE754

> [!abstract] 本章目标
> 能手工拆解一个 float 的位模式，知道精度损失从哪来，
> 以及为什么 `0.1 + 0.2 != 0.3`。
> 本项目的坐标、角度、FOV 全是 float。

> [!note] 承上
> 上一章讲整数在寄存器/内存里怎么摆。
> 本章讲**小数**在内存里怎么摆——IEEE754。它解释了坐标、角度、FOV 的精度问题。

## 先看那个著名的坑

```c
#include <stdio.h>

int main(void) {
    if (0.1 + 0.2 == 0.3)
        printf("相等\n");
    else
        printf("不相等！\n");
    printf("%.20f\n", 0.1 + 0.2);
    return 0;
}
```

输出：

```
不相等！
0.30000000000000004441
```

这不是 bug，是**二进制浮点数的固有性质**。

## 为什么：十进制的 0.1 在二进制里是无限小数

就像十进制里 `1/3 = 0.3333...` 永远写不完，
二进制里 `1/10 = 0.0001100110011...` 也永远写不完。

float 只有 23 位尾数，存不下无限小数 → 只能四舍五入 → 误差。

```
十进制 0.1
= 二进制 0.000110011001100110011001100...
                    ↑ 存到这里就截断了
```

## float 的位布局（IEEE754 单精度）

```
31  30                23  22                                     0
┌───┬───────────────────┬─────────────────────────────────────────┐
│ S │   Exponent (8bit) │        Mantissa / Fraction (23bit)      │
└───┴───────────────────┴─────────────────────────────────────────┘
符号位   指数（偏移 127）        尾数（隐含前导 1）
```

数值公式：

```
value = (-1)^S × (1 + Mantissa/2^23) × 2^(Exponent - 127)
```

| 部分 | 位数 | 说明 |
|---|---|---|
| S | 1 | 0=正，1=负 |
| E | 8 | 偏移 127，实际指数 = E - 127 |
| M | 23 | 小数部分，隐含整数部分是 1 |

特殊情况：

| E | M | 含义 |
|---|---|---|
| 0 | 0 | ±0 |
| 0 | ≠0 | 非规格化数（极小的数） |
| 255 | 0 | ±∞ |
| 255 | ≠0 | NaN |

## 手工拆解 3.14f

用第 04 章的 hexdump：

```c
float f = 3.14f;
hexdump(&f, 4);      // C3 F5 48 40
```

小端序，所以实际值是 `0x4048F5C3`。

```
0x4048F5C3 = 0100 0000 0100 1000 1111 0101 1100 0011

S   = 0                     → 正数
E   = 1000 0000 = 128       → 实际指数 = 128 - 127 = 1
M   = 100 1000 1111 0101 1100 0011

1.M = 1 + M/2^23
    = 1 + 0x48F5C3 / 8388608
    = 1 + 4781507 / 8388608
    = 1.5699999...

value = 1.57 × 2^1 = 3.14  ✓
```

## double（双精度）

```
63  62                52  51                                     0
┌───┬───────────────────┬─────────────────────────────────────────┐
│ S │   Exponent (11bit)│        Mantissa (52bit)                 │
└───┴───────────────────┴─────────────────────────────────────────┘
```

偏移 1023。有效数字约 15~16 位十进制。

| 类型 | 总位数 | 尾数 | 十进制有效位 | 范围 |
|---|---|---|---|---|
| `float` | 32 | 23 | ~7 位 | ±3.4×10^38 |
| `double` | 64 | 52 | ~15 位 | ±1.8×10^308 |

**本项目全部用 float**：
- 坐标、旋转、FOV 都是 float（游戏引擎也用 float）
- 矩阵 `float M[4][4]`
- 好处：省一半内存和带宽，SIMD 一次能处理 4 个

## 精度损失的三个来源

### 1. 表示误差（上面说的 0.1）

### 2. 大数吃小数

```c
float a = 1e8f;
float b = 1.0f;
float c = a + b;        // c == 1e8f，b 被"吃掉"了
printf("%f\n", c - a);  // 输出 0.000000
```

`1e8` 需要 27 位二进制精度，float 只有 24 位有效位 → 加 1 完全丢失。

**对本项目的影响**：世界坐标如果很大（比如 1e7 量级），
加上小偏移（比如骨骼偏移 0.1）会没有效果。这就是为什么"骨骼偏移"要在合理量级调整。

### 3. 累积误差

```c
float sum = 0;
for (int i = 0; i < 1000000; i++) sum += 0.1f;
printf("%f\n", sum);       // 期望 100000.0，实际约 99000 左右
```

一百万次加法，每次误差一点点，累积起来就偏了。

> [!tip] 本项目里的累积在哪
> 自瞄的"平滑"逻辑：
> ```cpp
> 累积角度.Pitch += sp;      // 每帧加一点
> ```
> 如果长时间运行，角度可能漂移。
> 解法：到位时直接赋值 `累积角度 = 目标角`（本项目就是这么做的）。

> [!note] 本章用到的数学函数（都在 `<math.h>`）
> 下面会用到几个 C 标准库的数学函数，**名字带 `f` 后缀的是 float 版**（不带的是 double 版）：
>
> | 函数 | 作用 |
> |---|---|
> | `fabsf(x)` / `fabs(x)` | 绝对值 |
> | `fmaxf(a,b)` / `fmax(a,b)` | 取较大者 |
> | `fminf(a,b)` | 取较小者 |
> | `sqrtf(x)` / `sqrt(x)` | 平方根（第 09 章用过，要 `-lm` 链接） |
> | `pow(x, y)` | x 的 y 次方 |
>
> 链接时记得加 `-lm`（链接数学库）。

## 正确的比较方式

```c
// 错误
if (a == b)

// 正确：比较差值是否足够小
#include <math.h>
if (fabsf(a - b) < 1e-6f)
```

绝对值阈值 vs 相对阈值：

```c
// 绝对（适合数值在 0 附近的场景）
bool nearly_equal_abs(float a, float b, float eps) {
    return fabsf(a - b) < eps;
}

// 相对（适合大数比较，更通用）
bool nearly_equal_rel(float a, float b, float eps) {
    float diff = fabsf(a - b);
    float scale = fmaxf(1.0f, fmaxf(fabsf(a), fabsf(b)));
    return diff < eps * scale;
}
```

本项目自瞄里判断"已经对准"：

```cpp
if (std::fabs(dp) <= 0.05f && std::fabs(dy) <= 0.05f) {
    累积角度 = 目标角;     // 直接赋值，避免无限逼近
}
```

用的是绝对阈值 0.05 度——对角度这个量级足够。

## NaN 与 Inf

```c
float a = 0.0f / 0.0f;      // NaN
float b = 1.0f / 0.0f;      // Inf
float c = -1.0f / 0.0f;     // -Inf
```

**NaN 的特性：任何与 NaN 的比较都是 false。**

```c
float n = 0.0f / 0.0f;
printf("%d\n", n == n);        // 0（false！）
printf("%d\n", n != n);        // 1（true！）
```

判断：`isnan(n)` 或 `n != n`。

Inf 会传染：

```c
1.0f / 0.0f        → inf
inf - inf          → nan
inf * 0            → nan
```

> [!danger] 本项目里的 NaN 防护
> ```cpp
> static bool IsFiniteScreenPoint(const Vector2A &point) {
>     return std::isfinite(point.X) && std::isfinite(point.Y);
> }
> 
> if (!IsFiniteScreenPoint(rootScreen) || ...) continue;
> ```
> 为什么必须判？因为除法的分母 `w` 可能接近 0：
> ```cpp
> float w = matrix[3]*obj.X + ... ;
> if (w < 0.001f) return false;      // 先拦住
> screen.X = px + (clip_x / w) * px; // 再除
> ```
> 少了 `w < 0.001f` 这一行，就会得到 inf/nan 坐标，
> 画出来的线会飞到屏幕外，或者让 ImGui 崩溃。

## float 与 int 的位级转换

想看 float 的位模式：

```c
float f = 3.14f;
uint32_t bits;
memcpy(&bits, &f, 4);          // 安全做法
printf("0x%08X\n", bits);      // 0x4048F5C3
```

反向：

```c
uint32_t bits = 0x4048F5C3;
float f;
memcpy(&f, &bits, 4);
printf("%f\n", f);             // 3.140000
```

> [!warning] 不要用 `*(uint32_t*)&f`
> 这违反了严格别名规则（strict aliasing），
> 在 `-O2` 下可能被优化成错误结果。
> 用 `memcpy` 或 C++20 的 `std::bit_cast`。

## 快速开方（了解历史）

经典技巧（Quake III 的 `0x5f3759df`）：

```c
float Q_rsqrt(float number) {
    long i;
    float x2, y;
    x2 = number * 0.5f;
    y = number;
    i = *(long*)&y;              // 位级 reinterpret
    i = 0x5f3759df - (i >> 1);   // 魔法
    y = *(float*)&i;
    y = y * (1.5f - (x2 * y * y));  // 牛顿迭代
    return y;
}
```

现代 CPU 有 `rsqrtss` 指令，比这还快。**别在生产代码里用这个**，但值得知道。

## 取整与截断

```c
#include <math.h>

floorf(3.7f)   → 3.0f      // 向下
ceilf(3.2f)    → 4.0f      // 向上
roundf(3.5f)   → 4.0f      // 四舍五入
truncf(3.7f)   → 3.0f      // 向零截断
```

**隐式截断**：

```c
float f = 3.9f;
int i = f;          // 3（直接截断，不四舍五入）
int j = (int)(f + 0.5f);   // 4（手动四舍五入，仅对正数有效）
```

本项目触摸坐标转换：

```cpp
req->vinput_info.x = static_cast<int>(normX * req->vinput_info.POSITION_X);
```

`static_cast<int>` 是截断。想四舍五入要 `+ 0.5f`。

## 动手：写一个 float 解析器

> [!tip] Windows 用户怎么办
> 本章代码是纯 C，**Windows 上用 w64devkit 的 gcc 就能编译**（`gcc parse_float.c -o parse_float.exe`）。

```c
#include <stdio.h>
#include <stdint.h>
#include <string.h>
#include <math.h>

void parse_float(float f) {
    uint32_t bits;
    memcpy(&bits, &f, 4);

    int sign     = (bits >> 31) & 1;
    int exponent = (bits >> 23) & 0xFF;
    uint32_t mant = bits & 0x7FFFFF;

    printf("%.6f  =  0x%08X\n", f, bits);
    printf("  符号  : %d (%s)\n", sign, sign ? "负" : "正");
    printf("  指数  : %d (实际 %d)\n", exponent, exponent - 127);
    printf("  尾数  : 0x%06X  (1 + %u/%u = %.9f)\n",
           mant, mant, 1u<<23, 1.0 + (double)mant / (1u<<23));

    if (exponent == 255)
        printf("  → %s\n", mant ? "NaN" : (sign ? "-Inf" : "+Inf"));
    else if (exponent == 0)
        printf("  → 非规格化数或 0\n");
    else
        printf("  → 值 = %+.9f\n",
               (sign ? -1.0 : 1.0) * (1.0 + (double)mant / (1u<<23))
               * pow(2.0, exponent - 127));
}

int main(void) {
    parse_float(3.14f);
    parse_float(1.0f);
    parse_float(0.0f);
    parse_float(-2.5f);
    parse_float(1.0f / 0.0f);
    parse_float(0.0f / 0.0f);
    return 0;
}
```

验证：3.14 的指数应该是 128（实际指数 1）。
