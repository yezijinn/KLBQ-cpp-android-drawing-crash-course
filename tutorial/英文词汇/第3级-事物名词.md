| `pixels` | pixel | 像素（多个）| `pixels per inch` = 屏幕密度 |
| `colors` | color | 颜色（多个）| 调色板配色数组 |
| `columns` | column | 列（多个）| 表格分栏 |
| `vertices` | vertex | 顶点（多个）| `vertices` 是**不规则复数**，不是 vertexs |
| `matrices` | matrix | 矩阵（多个）| 同理，不是 matrixs |
| `axes` | axis | 轴（多个）| 同理，不是 axises |
| `indices` | index | 下标（多个）| 图形学里读 `/ˈɪndɪsiːz/` |

> [!tip] 英语复数规则速记
> - 一般加 `-s`：`byte → bytes`
> - 以 s/x/z/ch/sh 结尾加 `-es`：`index → indexes`
> - 辅音 + y 结尾：`y → ies`：`dependency → dependencies`
> - **不规则**（必须背）：`vertex → vertices`、`matrix → matrices`、`axis → axes`、`index → indices`
> - **不变**：`data`（datum 的复数，但日常当单数用）、`code`、`info`
