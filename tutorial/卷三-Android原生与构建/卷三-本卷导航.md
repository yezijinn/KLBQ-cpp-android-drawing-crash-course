## 先修要求

- 卷一、卷二全部
- **一台 Android 设备**（真机或模拟器）；卷三后半（第 37 章起）需要 **root 设备**
- 没有 root 设备怎么办：第 32、37 章会说明替代方案（模拟器 + `adb root`）

## 学完你能做什么

- [ ] 用两条不同路线编译出 arm64 可执行文件（clang 直编 / ndk-build）
- [ ] 能逐行解释 `Android.mk` 和 `Application.mk`
- [ ] 会 push、chmod、运行、抓 logcat，并写成一键脚本
- [ ] 遇到 "Permission denied" 能判断是 DAC 还是 SELinux
- [ ] 会写分级日志，知道 `string_view` 必须用 `%.*s`
- [ ] 会引入第三方源码（ImGui）和预编译静态库（Embree）
- [ ] 会做体积裁剪（四件套），会算减了多少
- [ ] **有一个规范的工程骨架，能一键构建→推送→运行**

## 最容易卡住的三个地方

| 卡点 | 章节 | 建议 |
|---|---|---|
| **路径含中文/空格** | 33 | 立刻检查！这是"随机失败"的头号原因 |
| **ABI / API level 不匹配** | 39 | `file` + `readelf -h` 确认架构；`getprop` 确认设备 API |
| **私有库 dlopen 被拒** | 32、65 | 记住：App 不行，原生可执行文件可以 |

> [!tip] 本卷的学习方法
> 本卷最有效的学习方式是**故意制造错误**。
> 第 39 章列了 4 个坑，第 40 章做了 STL 对比，第 41 章做了 5 次构建对比——
> 全部亲手做一遍。你踩过的坑才会变成经验。

## 本卷综合练习

**目标**：搭出后面 56 章要用的基础工程。

要求：
1. 规范目录（include/src 镜像、按功能分层）
2. 引入 ImGui 源码 + 一个最小 Embree 库
3. 分级日志模块（第 38 章的 5 项要求全满足）
4. 一键脚本：编译 → push → chmod → 运行 → 抓日志
5. `.gitignore` 排除 `libs/` `obj/`
6. 在真机上跑起来并输出日志

**验收**：6 项全过。这个工程就是卷四~卷八的工作目录。
