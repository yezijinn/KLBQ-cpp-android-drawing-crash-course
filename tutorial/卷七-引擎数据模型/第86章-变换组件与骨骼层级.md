## 数据布局回顾

```cpp
#define BONE_STRIDE 48

struct BoneTransform {
    Quat Rotation;     // 0x00  16 字节
    Vec3 Translation;  // 0x10  12 字节
    Vec3 Scale3D;      // 0x1C  12 字节
};                     // 40 字节，但步长 48
```

第 48 章讲过：**步长用常量 48，不用 `sizeof`（40）**。

## 计算世界坐标

```cpp
inline Vector3A GetBoneWorldPos(uint64_t boneArray, int index, const Matrix& c2w) {
    return MarixToVector(MatrixMulti(
        TransformToMatrix(getBone(boneArray + index * BONE_STRIDE)),
        c2w
    ));
}
```

两步：
1. `getBone()` 读 48 字节 → 四元数/位置/缩放
2. `TransformToMatrix()` 转成矩阵
3. `MatrixMulti(局部, C2W)` 得到世界矩阵
4. `MarixToVector()` 取第 4 行 = 世界坐标

void InitHumanSkeleton(PaddedBone *bones, Vec3 rootPos) {

    memset(bones, 0, BONE_COUNT * sizeof(PaddedBone));

## 从外部读骨骼

```cpp
struct BoneSnapshot {
    Vec3 world;
    bool valid;
};

std::vector<BoneSnapshot> ReadSkeleton(MemReader &mem,
                                        uint64_t boneArray,
                                        int count,
                                        const Matrix &c2w) {
    std::vector<BoneSnapshot> out;
    if (!boneArray || count <= 0 || count > 256) return out;

    // 一次读整个骨骼数组（1 次 I/O！）
    size_t total = count * BONE_STRIDE;
    std::vector<uint8_t> raw(total);
    if (mem.Read(boneArray, raw.data(), total) <= 0) return out;

    // 本地解析，零 I/O
    out.resize(count);
    for (int i = 0; i < count; i++) {
        const uint8_t *p = raw.data() + i * BONE_STRIDE;
        BoneTransform bt;
        memcpy(&bt, p, sizeof(BoneTransform));      // 前 40 字节

        Matrix local = TransformToMatrix(bt);
        Matrix world = MatrixMulti(local, c2w);
        out[i].world = MatrixGetPosition(world);
        out[i].valid = IsFiniteVec3(out[i].world);
    }
    return out;
}
```

**一次 I/O 读完 56 根骨骼（2688 字节）**，之后全在本地算。

对比逐个读：56 次 I/O → 1 次，**快 56 倍**。

## 瞄准点选择

```cpp
Vec3 瞄准点(rootWorld.X, rootWorld.Y, rootWorld.Z + Cfg.高度偏移);   // 默认 +90

if (Cfg.骨骼部位 != 0) {
    const uint64_t mesh = dr->Read<uint64_t>(objectAddress + 0x370);
    if (IsValidObject(mesh)) {
        const uint64_t bone = dr->Read<uint64_t>(mesh + 0x578);
        if (IsValidObject(bone)) {
            const Matrix c2w = TransformToMatrix(getBone(mesh + 0x2A0));
            const Vector3A bw = GetBoneWorldPos(bone, Cfg.骨骼部位, c2w);
            if (std::isfinite(bw.X) && ...) {
                瞄准点 = Vec3(bw.X, bw.Y, bw.Z);
            }
        }
    }
}
```

两种模式：
- `骨骼部位 = 0`：根节点 + 高度偏移（降级方案，骨骼读不到时仍可用）
- `骨骼部位 = 7/6/1`：头/胸/骨盆

**降级设计值得学习**：关键功能要有备用路径。

## 动手：端到端验证

1. 给 demo 引擎加上骨骼（上面的代码）
2. 让 demo 打印每根骨骼的世界坐标（自己算一遍）
3. 用外部程序读取并计算
4. **逐根对比，必须完全一致**

试着故意改错：
- 把 `BONE_STRIDE` 改成 40 → 所有骨骼位置全错
- 把 `componentToWorld` 的偏移改错 → 整体平移/旋转错误
- 忘记判 `IsFinite` → 出现飞线

**每种错误都亲手犯一次**，以后遇到类似症状就知道往哪查。
