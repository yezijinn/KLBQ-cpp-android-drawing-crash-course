## 数据布局回顾

```cpp
#define BONE_STRIDE 48

struct BoneTransform {
    Quat Rotation;     // 0x00  16 字节
    Vec3 Translation;  // 0x10  12 字节
    Vec3 Scale3D;      // 0x1C  12 字节
};                     // 40 字节，但步长 48
```

第 48 章讲过：**步长用常量 48，不用 `sizeof`（40）**。

## 计算世界坐标

```cpp
inline Vector3A GetBoneWorldPos(uint64_t boneArray, int index, const Matrix& c2w) {
    return MarixToVector(MatrixMulti(
        TransformToMatrix(getBone(boneArray + index * BONE_STRIDE)),
        c2w
    ));
}
```

四步：
1. `getBone()` 读 **40 字节**（`sizeof(BoneTransform)`）→ 四元数/位置/缩放
2. `TransformToMatrix()` 转成矩阵
3. `MatrixMulti(局部, C2W)` 得到世界矩阵
4. `MarixToVector()` 取第 4 行 = 世界坐标

> [!note] 读 40 字节，但地址按 48 步长推进
> 每根骨骼的**结构体是 40 字节**，但引擎给每根骨骼留了 **48 字节**（多 8 字节填充）。
> 所以：`getBone(boneArray + index * BONE_STRIDE)` —— 用 `index * 48` 算地址，
> 但读的时候只读 40 字节。**步长≠结构体大小**，这是本项目最容易错的地方（第 07、48 章）。

## 从外部读骨骼

```cpp
struct BoneSnapshot {
    Vec3 world;
    bool valid;
};

std::vector<BoneSnapshot> ReadSkeleton(MemReader &mem,
                                        uint64_t boneArray,
                                        int count,
                                        const Matrix &c2w) {
    std::vector<BoneSnapshot> out;
    if (!boneArray || count <= 0 || count > 256) return out;

    // 一次读整个骨骼数组（1 次 I/O！）
    size_t total = count * BONE_STRIDE;
    std::vector<uint8_t> raw(total);
    if (mem.Read(boneArray, raw.data(), total) <= 0) return out;

    // 本地解析，零 I/O
    out.resize(count);
    for (int i = 0; i < count; i++) {
        const uint8_t *p = raw.data() + i * BONE_STRIDE;
        BoneTransform bt;
        memcpy(&bt, p, sizeof(BoneTransform));      // 前 40 字节

        Matrix local = TransformToMatrix(bt);
        Matrix world = MatrixMulti(local, c2w);
        out[i].world = MatrixGetPosition(world);
        out[i].valid = IsFiniteVec3(out[i].world);
    }
    return out;
}
```

**一次 I/O 读完 56 根骨骼（2688 字节）**，之后全在本地算。

对比逐个读：56 次 I/O → 1 次，**快 56 倍**。

### 习题 86.1 四元数转旋转矩阵并计算骨骼世界坐标（★★★）

**任务要求**：实现 `TransformToMatrix`（四元数→矩阵）和 `GetBoneWorldPos`，
验证"父级矩阵 × 局部矩阵"链式相乘得到世界坐标。

**核心骨架**（与本项目 `variable.h` 一致）：

```cpp
#include <cstdio>
#include <cmath>
#include <cstdint>
#include <cstring>
#include <cassert>

struct Quat { float x, y, z, w; };
struct Vec3 { float x, y, z; };
struct Mat4 { float m[4][4] = {}; };

// 四元数 + 平移 + 缩放 → 4x4 矩阵（本项目的 TransformToMatrix）
Mat4 TransformToMatrix(const Quat& r, const Vec3& t, const Vec3& s) {
    Mat4 M;
    M.m[3][0] = t.x; M.m[3][1] = t.y; M.m[3][2] = t.z;
    float x2=r.x+r.x, y2=r.y+r.y, z2=r.z+r.z;
    float xx2=r.x*x2, yy2=r.y*y2, zz2=r.z*z2;
    M.m[0][0] = (1-(yy2+zz2))*s.x;
    M.m[1][1] = (1-(xx2+zz2))*s.y;
    M.m[2][2] = (1-(xx2+yy2))*s.z;
    float yz2=r.y*z2, wx2=r.w*x2;
    M.m[2][1] = (yz2-wx2)*s.z; M.m[1][2] = (yz2+wx2)*s.y;
    float xy2=r.x*y2, wz2=r.w*z2;
    M.m[1][0] = (xy2-wz2)*s.y; M.m[0][1] = (xy2+wz2)*s.x;
    float xz2=r.x*z2, wy2=r.w*y2;
    M.m[2][0] = (xz2+wy2)*s.z; M.m[0][2] = (xz2-wy2)*s.x;
    M.m[0][3] = M.m[1][3] = M.m[2][3] = 0;
    M.m[3][3] = 1;
    return M;
}

Mat4 Mul(const Mat4& a, const Mat4& b) {
    Mat4 r;
    for (int i=0;i<4;i++) for (int j=0;j<4;j++)
        for (int k=0;k<4;k++) r.m[i][j] += a.m[i][k]*b.m[k][j];
    return r;
}
```

**验证断言**（接上面的 `Quat`/`Vec3`/`Mat4`/`TransformToMatrix`/`Mul` 定义，拼成一个文件后编译）：

```cpp
int main() {
    // 单位四元数（无旋转），平移 (100, 200, 50)，缩放 1
    Quat id{0, 0, 0, 1};
    Vec3 one{1, 1, 1};
    Mat4 local = TransformToMatrix(id, {100, 200, 50}, one);
    Mat4 c2w   = TransformToMatrix(id, {0, 0, 0}, one);   // 组件到世界：无变换
    Mat4 world = Mul(local, c2w);

    // 世界坐标在 M[3][0..2]
    printf("骨骼世界坐标 = (%.0f, %.0f, %.0f)\n", world.m[3][0], world.m[3][1], world.m[3][2]);
    assert(fabsf(world.m[3][0] - 100) < 0.01f);
    assert(fabsf(world.m[3][1] - 200) < 0.01f);
    assert(fabsf(world.m[3][2] - 50)  < 0.01f);
    printf("习题 86.1 全部通过\n");
    return 0;
}
```

**验证断言**：单位四元数 + 平移 `(100,200,50)`，世界坐标应为 `(100,200,50)`。

> [!tip] 这道题练什么
> ① **四元数→矩阵**的标准公式（本项目的 `TransformToMatrix`）；
> ② **父级 × 局部**（`Mul(local, c2w)`）——本项目源码就是这个顺序；
> ③ **世界坐标在 `M[3][0..2]`**（行向量约定，平移写在最后一行）。

### 习题 86.2 步长 48 vs 结构 40（★★）

**任务要求**：数组按 48 字节步长存储 40 字节的结构体，验证第 index 根的地址。

**参考实现**：

```cpp
#include <cstdio>
#include <cstdint>
#include <cassert>

#define BONE_STRIDE 48
#define BONE_COUNT  56

int main() {
    // 按 48 步长算第 index 根骨骼的地址
    uint64_t base = 0x10000;
    for (int i = 0; i < BONE_COUNT; i++) {
        uint64_t addr = base + (uint64_t)i * BONE_STRIDE;
        if (i == 7) {   // 第 7 根（头）
            printf("第 %d 根骨骼地址 = 0x%llX\n", i, (unsigned long long)addr);
            assert(addr == base + 7 * 48);
        }
    }
    // 最后一根不越界
    uint64_t last = base + (uint64_t)(BONE_COUNT - 1) * BONE_STRIDE;
    assert(last == base + 55 * 48);
    printf("习题 86.2 全部通过\n");
    return 0;
}
```

> [!danger] 用 sizeof 会少分配
> 若按 `sizeof(BoneTransform)`（40）分配 56 根，只分配 2240 字节；
> 按 48 步长实际需要 56×48 = 2688 字节。**少分配 448 字节 → 读第 55 根时越界**。
> 这就是本项目 `malloc(BONE_COUNT * BONE_STRIDE)` 的原因。
