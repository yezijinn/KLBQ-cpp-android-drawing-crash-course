# 第 48 章 · 局部空间与父子变换链

> [!abstract] 本章目标
> 理解骨骼层级和"父级矩阵 × 局部矩阵"的链式计算，
> 这正是本项目 `GetBoneWorldPos` 在做的事。

> [!note] 承上
> 上一章学了单个旋转。
> 本章讲**变换的组合**：骨骼是一层套一层的（父级 × 局部 = 世界），这就是 `GetBoneWorldPos` 在做的事。

## 先看一个具体的骨骼计算

本项目读骨骼世界坐标的代码（`variable.h`）：

```cpp
inline Vector3A GetBoneWorldPos(uint64_t boneArray, int index, const Matrix& c2w) {
    return MarixToVector(MatrixMulti(
        TransformToMatrix(getBone(boneArray + index * BONE_STRIDE)),  // 骨骼局部变换
        c2w                                                            // 组件到世界
    ));
}
```

一行里包含两个概念：**局部变换** 和 **父级矩阵**。

## 为什么需要"局部空间"

想象一个角色：

```
角色（在世界的 (100, 200, 0)，朝北）
  └─ 骨盆
       └─ 脊柱
            ├─ 左肩 → 左上臂 → 左小臂 → 左手
            └─ 右肩 → 右上臂 → 右小臂 → 右手
```

如果每根骨骼都存"世界坐标"，角色一走动，**所有骨骼都要重算**。

更聪明的办法：每根骨骼只存**相对于父骨骼的变换**。

```
手的局部变换：相对小臂，偏移 (30, 0, 0)
小臂的局部变换：相对上臂，偏移 (25, 0, 0)
...
角色根节点：相对世界，位置 (100, 200, 0)
```

角色走动时，只改根节点的变换，其余自动跟着走。

**这就是骨骼动画的基础。**

## 父级矩阵 × 局部矩阵 = 世界矩阵

> [!note] 本节的乘法顺序统一用列向量约定
> 即 `v' = M · v`（点写成一列、矩阵在左），**右边的矩阵先作用**。
> 这是第 46 章讲的"讲数学时用"的约定。源码里的顺序可能相反（见下文说明）。

```
骨骼的世界矩阵 = 父骨骼世界矩阵 × 骨骼局部矩阵
```

递归展开（越靠右的矩阵越先作用，即"局部先作用，逐级往上"）：

```
手的世界 = 小臂世界 × 手局部
         = (上臂世界 × 小臂局部) × 手局部
         = 根节点世界 × ... × 上臂局部 × 小臂局部 × 手局部
```

**一串矩阵连乘。**

本项目的简化：UE4 已经把"从骨骼到组件的变换"算好存在骨骼数组里，
所以只需要再乘一次"组件到世界（C2W）"：

```cpp
const Matrix c2w = TransformToMatrix(getBone(mesh + 0x2A0));   // 组件到世界
const Vector3A bw = GetBoneWorldPos(bone, 骨骼部位, c2w);
```

> [!note] 为什么 UE4 里只乘一次
> UE4 的骨骼数组（`boneArray`）存的是**已经计算好的相对组件空间的变换**
> （引擎每帧在动画线程算完链）。
> 所以外部程序不需要自己遍历整条链——这是引擎帮我们做好的优化。

## 变换链的顺序问题

回顾第 46 章：**矩阵乘法不可交换**。

```
（数学标准写法）世界 = 父级 × 局部
```

直觉理解：局部变换是"在这个父级的坐标系里"做的，
所以**先应用局部**（把点从骨骼局部坐标转到父级坐标），
**再应用父级**（继续往上传）。

数学上：向量写在右边，越靠右的矩阵越先作用：

```
v_world = M_parent × M_local × v_local
                       ↑ 先做（局部先作用）
```

> [!note] 为什么写成 `M_parent × M_local` 而不是反过来
> 上面这个公式用的是**列向量约定**（点写成一列、矩阵在左），
> 也是大多数教材和 OpenGL 的写法，本教程**统一按它讲数学**。
> 本章最后的动手 demo 用的就是它：`Mul(actorToWorld, pelvisLocal)`（父级在前）。

本项目源码写的是 `MatrixMulti(local, c2w)`，
即 `result = local × c2w`——**看起来和上面相反**。

> [!warning] 这与标准写法"相反"？
> 标准写法是 `M_world = M_parent × M_local`。
> 本项目是 `local × c2w`。
>
> 差异在于**行主序 vs 列主序的约定**（第 46 章）。
> 项目内部是**自洽**的——`MarixToVector` 取 `M[3][0..2]` 作为平移，
> 与 `TransformToMatrix` 把平移写在 `M[3][0..2]` 一致。
>
> 你自己写库时，**选一种约定并全程坚持**，
> 然后用"单位变换 + 已知平移"做测试验证。

## 骨骼数据结构

本项目：

```cpp
#define BONE_STRIDE 48

struct BoneTransform {
    Quat Rotation;     // 0x00  四元数（16 字节）
    Vec3 Translation;  // 0x10  位置（12 字节）
    Vec3 Scale3D;      // 0x1C  缩放（12 字节）
};                     // 共 40 字节，但步长是 48
```

第 07 章讲过：`sizeof = 40`，`BONE_STRIDE = 48`，**步长用常量不用 sizeof**。

索引（第 07 章的 `BoneIndex` 枚举）：

```
BONE_PELVIS     = 1    骨盆（根）
BONE_CHEST      = 6    胸
BONE_HEAD       = 7    头
BONE_L_SHOULDER = 8    左肩
BONE_L_ELBOW    = 10   左肘
BONE_L_WRIST    = 11   左手
BONE_R_SHOULDER = 30   右肩
...
BONE_R_ANKLE    = 55   右踝
```

注意索引**不连续**（8 之后直接 30）——中间是手指等细节骨骼。

## 读一根骨骼的完整流程

```
1. 从 Actor 读 Mesh 指针        objectAddress + 0x370
2. 从 Mesh 读骨骼数组            mesh + 0x578
3. 从 Mesh 读组件到世界变换      mesh + 0x2A0
4. 读第 index 根骨骼             boneArray + index * 48
5. 四元数+位置+缩放 → 矩阵
6. 局部矩阵与 C2W 相乘 = 世界矩阵（源码写作 MatrixMulti(local, c2w)，顺序看起来与数学公式相反，见前文说明）
7. 取第 4 行 = 世界坐标
```

对应代码：

```cpp
const uint64_t mesh = dr->Read<uint64_t>(objectAddress + 0x370);
if (!IsValidObject(mesh)) continue;

const uint64_t bone = dr->Read<uint64_t>(mesh + 0x578);
if (!IsValidObject(bone)) continue;

const Matrix c2w = TransformToMatrix(getBone(mesh + 0x2A0));
const Vector3A bw = GetBoneWorldPos(bone, BONE_HEAD, c2w);
```

**每一步都要判空**。第 89 章会系统讲这个防御体系。

## 骨骼坐标的用途

| 用途 | 用哪根骨骼 |
|---|---|
| ESP 方框 | 根节点位置 + 固定高度 |
| 骨骼连线 | 15 根（头/胸/骨盆/四肢） |
| 自瞄瞄准点 | 头(7) / 胸(6) / 骨盆(1) |

本项目瞄准点配置：

```cpp
Vec3 瞄准点(rootWorld.X, rootWorld.Y, rootWorld.Z + Cfg.高度偏移);  // 默认 +90

if (Cfg.骨骼部位 != 0) {
    // 用骨骼

```

`骨骼部位 = 0` 表示"不用骨骼，用根节点 + 高度偏移"（降级方案）。

## 局部空间的其它例子

不只是骨骼，任何有层级的东西都用它：

| 场景 | 层级 |
|---|---|
| 骨骼 | 角色 → 骨 → 骨 → 骨 |
| 场景图 | 世界 → 关卡 → Actor → 组件 |
| UI | 窗口 → 面板 → 按钮 → 文字 |
| 相机 | 相机 → 手臂（武器）→ 枪口 |

理解"父级 × 局部"这条链式法则，就能理解所有层级系统。

## 动手：手算一条骨骼链

不读内存，纯数学模拟：

```cpp
#include <cstdio>
#include <cmath>
#include <cassert>

struct Vec3 { float x=0,y=0,z=0; };
struct Mat4 { float M[4][4] = {}; };

Mat4 Identity() {
    Mat4 m; for (int i=0;i<4;i++) m.M[i][i] = 1.0f; return m;
}
Mat4 Translation(float x, float y, float z) {
    Mat4 m = Identity();
    m.M[3][0]=x; m.M[3][1]=y; m.M[3][2]=z; return m;
}
Mat4 Mul(const Mat4 &a, const Mat4 &b) {
    Mat4 r;
    for (int i=0;i<4;i++) for (int j=0;j<4;j++) for (int k=0;k<4;k++)
        r.M[i][j] += a.M[i][k]*b.M[k][j];
    return r;
}
Vec3 Pos(const Mat4 &m) { return {m.M[3][0], m.M[3][1], m.M[3][2]}; }

int main(void) {
    // 角色在世界 (100, 200, 0)
    Mat4 actorToWorld = Translation(100, 200, 0);

    // 骨盆：相对角色 +10 高度
    Mat4 pelvisLocal = Translation(0, 0, 10);
    // 脊柱：相对骨盆 +40
    Mat4 spineLocal  = Translation(0, 0, 40);
    // 头：相对脊柱 +20
    Mat4 headLocal   = Translation(0, 0, 20);

    // 逐级累乘：world = parent × local（父级在前，见正文说明）
    // 本 demo 是纯平移，结果与存储约定无关，怎么数都对
    Mat4 pelvisWorld = Mul(actorToWorld, pelvisLocal);
    Mat4 spineWorld  = Mul(pelvisWorld,  spineLocal);
    Mat4 headWorld   = Mul(spineWorld,   headLocal);

    Vec3 pHead = Pos(headWorld);
    printf("头世界坐标: (%.0f, %.0f, %.0f)\n", pHead.x, pHead.y, pHead.z);
    // 期望 (100, 200, 70)
    assert(pHead.z == 70.0f);

    // 角色移动到 (500, 500, 0)，只需改根节点
    Mat4 moved = Translation(500, 500, 0);
    Mat4 headMoved = Mul(Mul(Mul(moved, pelvisLocal), spineLocal), headLocal);
    Vec3 p2 = Pos(headMoved);
    printf("移动后头坐标: (%.0f, %.0f, %.0f)\n", p2.x, p2.y, p2.z);
    // 期望 (500, 500, 70) —— 局部变换完全没变
    assert(p2.x == 500 && p2.z == 70);

    printf("全部通过\n");
    return 0;
}
```

关键观察：**移动角色只改了根节点，三根骨骼的局部变换一个字没动**。
这就是局部空间的价值。

## 课后习题

### 习题 48.1 手写 2D 父级×局部变换链（★★）

**任务要求**：用一个简化的 2D 情形理解「父级×局部」链：
父节点在 (100, 0) 且旋转 90°，子节点相对父级偏移 (10, 0)。
用矩阵乘算出子节点的世界坐标，并写断言验证。

**核心骨架**（3x3 齐次矩阵，2D 版）：

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

constexpr float PI = 3.14159265358979323846f;

struct Mat3 { float m[3][3]; };

// 平移矩阵
Mat3 Translation(float tx, float ty) {
    return {{{1,0,tx},{0,1,ty},{0,0,1}}};
}
// 绕原点旋转矩阵（列向量约定）
Mat3 Rotation(float deg) {
    float r = deg * PI / 180.0f, c = cosf(r), s = sinf(r);
    return {{{c,-s,0},{s,c,0},{0,0,1}}};
}
// 矩阵乘
Mat3 Mul(const Mat3& a, const Mat3& b) {
    Mat3 r{};
    for (int i=0;i<3;i++) for (int j=0;j<3;j++)
        for (int k=0;k<3;k++) r.m[i][j] += a.m[i][k]*b.m[k][j];
    return r;
}
// 变换一个点
void Apply(const Mat3& m, float x, float y, float* ox, float* oy) {
    *ox = m.m[0][0]*x + m.m[0][1]*y + m.m[0][2];
    *oy = m.m[1][0]*x + m.m[1][1]*y + m.m[1][2];
}
```

**参考实现**：

```cpp
int main() {
    // 父级：先转 90°，再平移到 (100,0)：M_parent = T * R
    Mat3 parent = Mul(Translation(100, 0), Rotation(90));
    // 子级相对父级：偏移 (10, 0) 且不旋转：M_local = T(10,0)
    Mat3 local = Translation(10, 0);
    // 世界矩阵 = 父级 × 局部（列向量约定，右边先作用）
    Mat3 world = Mul(parent, local);

    float wx, wy;
    Apply(world, 0, 0, &wx, &wy);   // 子节点在自身坐标系的原点
    printf("子节点世界坐标 = (%.2f, %.2f)\n", wx, wy);

    // 父级旋转 90° 后，局部偏移 (10,0) 变成世界里的 (0,10)，再平移到 (100,0)
    assert(fabsf(wx - 100.0f) < 0.01f);
    assert(fabsf(wy - 10.0f)  < 0.01f);

    // 验证「父动子动、局部不变」：父级平移到 (200,0)
    Mat3 parent2 = Mul(Translation(200, 0), Rotation(90));
    Mat3 world2 = Mul(parent2, local);
    Apply(world2, 0, 0, &wx, &wy);
    printf("父级移动到 (200,0) 后，子节点 = (%.2f, %.2f)\n", wx, wy);
    assert(fabsf(wx - 200.0f) < 0.01f);
    assert(fabsf(wy - 10.0f)  < 0.01f);   // 局部偏移不变

    printf("习题 48.1 全部通过\n");
    return 0;
}
```

**验证断言**：见上面 `main` 里的两条 `assert`——子节点世界坐标应为 `(100, 10)`；父级移到 `(200,0)` 后应为 `(200, 10)`（局部不变）。

> [!tip] 这道题练什么
> ① **「父级×局部」的乘法顺序**（列向量约定，右边先作用）；② **「父动子动、局部不变」**——
> 这正是骨骼动画的核心：角色走动只改根节点，所有子骨骼自动跟着走。
> 做完再回看本章 `GetBoneWorldPos`，就彻底通了。

## 常见坑排查表

| 症状 | 最可能的原因 | 解法 |
|---|---|---|
| 骨骼位置**整体偏移** | 根节点（C2W）读错 | 先验证根节点世界坐标 |
| 子骨骼**跑飞** | 乘法顺序反了 | 列向量约定：`父级 × 局部`（父级在前）|
| 骨骼**不跟角色动** | 用了局部坐标当世界坐标 | `world = parent × local` |
| 索引不连续**读错骨骼** | 假设了连续索引 | 本项目骨骼索引不连续（8 后是 30）|

### 测试脚本（保存为 ch48_test.cpp）

```cpp
// ch48_test.cpp —— 第48章父子变换链单元自测（自包含）
#include <cstdio>
#include <cassert>
#include <cmath>

struct Vec3 {
    float x=0, y=0, z=0;
    Vec3() = default;
    Vec3(float a, float b, float c) : x(a), y(b), z(c) {}
};
struct Matrix { float M[4][4]; };

Matrix Identity() { Matrix m={}; for(int i=0;i<4;i++) m.M[i][i]=1; return m; }
Matrix Translate(float tx,float ty,float tz){ Matrix m=Identity(); m.M[3][0]=tx; m.M[3][1]=ty; m.M[3][2]=tz; return m; }
Matrix MatrixMulti(const Matrix&m1,const Matrix&m2){
    Matrix r={};
    for(int i=0;i<4;i++)for(int j=0;j<4;j++)for(int k=0;k<4;k++)
        r.M[i][j]+=m1.M[i][k]*m2.M[k][j];
    return r;
}
Vec3 MarixToVector(const Matrix&m){ return Vec3(m.M[3][0],m.M[3][1],m.M[3][2]); }

static bool near(float a,float b,float e=1e-4f){ return std::fabs(a-b)<e; }

// 本项目骨骼：结构体 40 字节，但步长常量是 48
struct BoneTransform { float rot[4]; Vec3 translation; Vec3 scale; };
#define BONE_STRIDE 48

int main() {
    // ===== Arrange: 角色在世界 (100,200,0)，骨盆局部偏移 (0,0,90) =====
    Matrix actorToWorld = Translate(100.0f, 200.0f, 0.0f);   // 父级
    Matrix pelvisLocal  = Translate(0.0f, 0.0f, 90.0f);      // 局部

    // ===== Act: 父级 × 局部（列向量约定，父级在前）=====
    Matrix pelvisWorld = MatrixMulti(actorToWorld, pelvisLocal);
    Vec3 world = MarixToVector(pelvisWorld);

    // ===== Assert: 正常路径 =====
    // 骨盆世界坐标应为 (100, 200, 90)
    assert(near(world.x,100) && near(world.y,200) && near(world.z,90));
    std::printf("[PASS] 父级×局部 = 骨骼世界坐标 (100,200,90)\n");

    // 纯平移可交换：父级·局部 = 局部·父级（平移分量相加）
    Matrix rev = MatrixMulti(pelvisLocal, actorToWorld);
    Vec3 revWorld = MarixToVector(rev);
    assert(near(revWorld.x,100) && near(revWorld.y,200) && near(revWorld.z,90));
    std::printf("[PASS] 平移复合 = 平移相加（纯平移可交换）\n");

    // 三级链：角色 → 骨盆 → 头
    Matrix headLocal = Translate(0.0f, 0.0f, 60.0f);   // 头相对骨盆
    Matrix chain = MatrixMulti(MatrixMulti(actorToWorld, pelvisLocal), headLocal);
    Vec3 headWorld = MarixToVector(chain);
    assert(near(headWorld.z, 150));    // 0 + 90 + 60
    std::printf("[PASS] 三级父子链累加 (z=150)\n");

    // ===== 反向异常路径 =====
    // 步长常量 48 与结构体 40 的区别（本项目最易错点）
    static_assert(BONE_STRIDE == 48, "步长必须是 48");
    assert(sizeof(BoneTransform) == 40);   // rot(16)+translation(12)+scale(12)=40
    assert(BONE_STRIDE != sizeof(BoneTransform));
    // 索引不连续：第 8 根后直接第 30 根，地址差 = (30-8)*48
    uintptr_t base = 0x1000;
    uintptr_t addr8  = base + 8  * BONE_STRIDE;
    uintptr_t addr30 = base + 30 * BONE_STRIDE;
    assert((addr30 - addr8) == 22 * 48);
    std::printf("[PASS] 反向: 步长48≠结构体40, 索引不连续\n");

    std::printf("\n第48章 全部断言通过\n");
    return 0;
}
```
