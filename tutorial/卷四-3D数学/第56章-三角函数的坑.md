> [!note] 承上

## 坑一：度与弧度

C 标准库的三角函数**只接受弧度**：

```cpp
sin(90);       // 错误！90 弧度 ≈ 14.3 圈
sin(90 * PI / 180);   // 正确
```

| 函数 | 输入 | 输出 |
|---|---|---|
| `sinf` `cosf` `tanf` | 弧度 | 比值 |
| `asinf` `acosf` `atanf` | 比值 | **弧度** |
| `atan2f(dy, dx)` | 比值 | **弧度** |

转换：

```cpp
constexpr float DEG2RAD = 3.14159265358979323846f / 180.0f;
constexpr float RAD2DEG = 180.0f / 3.14159265358979323846f;

float rad = deg * DEG2RAD;
float deg = rad * RAD2DEG;
```

本项目的写法：

```cpp
float radPitch = rotation.Pitch * ((float) M_PI / 180.0f);
...
r.Pitch = std::atan2(v.z, 水平) * 180.0f / PI_F;
```

**每次调用都要转**——忘了转是最常见的错误，症状是"数值完全不对但程序能跑"。

> [!tip] 用命名避免混淆
> 变量名带单位：`pitchDeg` / `pitchRad`，或者 `角度` / `弧度`。
> 本项目用了中文变量名就清晰很多（`相机旋转` 是度，因为内存里存的是度）。

## 坑二：`atan` 丢失象限信息

```cpp
float angle = atanf(dy / dx);      // 只有 -90° ~ +90°
```

问题：`dy/dx` 这个比值丢失了符号信息。

```
(dx, dy) = (1, 1)    → dy/dx = 1   → atan = 45°    ✓
(dx, dy) = (-1, -1)  → dy/dx = 1   → atan = 45°    ✗ 应该是 225°(或 -135°)
```

**两个方向完全不同的向量，商相同。**

而且 `dx = 0` 时除零。

### 正确做法：`atan2(dy, dx)`

```cpp
atan2f(1, 1)    →  0.785  (45°)
atan2f(-1, -1)  → -2.356  (-135°)   ✓ 正确
atan2f(1, 0)    →  1.571  (90°)     ✓ 不除零
```

`atan2` 接受两个参数，能区分四个象限，返回值范围 `(-π, π]`。

本项目的用法：

```cpp
inline Rotator 向量转角度(const Vec3 &v) {
    const float 水平 = std::sqrt(v.x * v.x + v.y * v.y);
    Rotator r{};
    r.Pitch = std::atan2(v.z, 水平) * 180.0f / PI_F;   // ← atan2
    r.Yaw   = std::atan2(v.y, v.x)  * 180.0f / PI_F;   // ← atan2
    r.Roll  = 0.0f;
    return r;
}
```

注意第一个参数 `atan2(v.z, 水平)`：`水平` 是水平投影长度，
**永远非负**，所以 Pitch 范围是 `[-90°, +90°]`——正确（俯仰不会超过垂直）。

## 坑三：角度的周期性与"绕远路"

角度是周期的：350° 和 -10° 是同一个方向。

```cpp
// 从 350° 转到 10°
float delta = 10 - 350;        // -340
// 按这个转，要往回转 340 度！
// 实际最短路径是 +20 度
```

本项目的解法（第 47 章讲过）：

```cpp
inline float 归一角差(float a, float b) {
    float d = a - b;
    while (d >  180.0f) d -= 360.0f;
    while (d < -180.0f) d += 360.0f;
    return d;
}
```

**自瞄转错方向是很容易观察到的 bug**——
屏幕上准星会往反方向甩一大圈。

## 坑四：`acos` 的精度悬崖

用点积求夹角：

```cpp
float cosA = Dot(a, b);        // 假设 a,b 已归一化
float angle = acosf(cosA);
```

问题：`cos` 在 0° 附近变化极慢：

```
cos(0°)   = 1.0
cos(1°)   = 0.99985
cos(0.1°) = 0.9999985
```

float 只有 7 位有效位，1° 和 0° 的 cos 值在第 5 位才不同——
**小角度的精度极差**。

而且浮点误差可能让 `cosA` 略大于 1：

```cpp
float cosA = 1.0000001f;       // 理论上不可能，但浮点误差会产生
acosf(cosA);                   // nan！
```

> [!danger] acos 必须 clamp
> ```cpp
> float cosA = std::clamp(Dot(a, b), -1.0f, 1.0f);
> float angle = acosf(cosA);
> ```
>
> **这就是为什么本项目自瞄不用点积判角度**，
> 而是把方向转成欧拉角再比较（第 47 章的 `向量转角度` + `归一角差`）。
> 转角度用的是 `atan2`，没有这个精度悬崖，也没有 nan 风险。

## 坑五：`asin`/`acos` 的结果范围

| 函数 | 输入范围 | 输出范围 |
|---|---|---|
| `asinf` | [-1, 1] | `[-π/2, π/2]` |
| `acosf` | [-1, 1] | `[0, π]` |
| `atanf` | 任意 | `(-π/2, π/2)` |
| `atan2f` | 任意 | `(-π, π]` |

`asin`/`acos` 输入超出 [-1,1] 直接返回 NaN。
**必须 clamp**。

`atan2` 输出覆盖整圈 360°，是唯一能直接得到"方位角"的函数。

## 坑六：三角函数的性能

`sinf`/`cosf` 大约 **20~50 个时钟周期**，`atan2f` 更贵（100+）。

本项目每帧要算多少次？

```cpp
// camMakeMatrix：4 次（sin/cos × 2 + tan）
// GetForward：4 次
// 向量转角度：每个候选目标 1 次 sqrt + 2 次 atan2
// 骨骼变换：四元数转矩阵，无三角函数（好）
```

假设 50 个可见目标：`50 × 2 = 100` 次 `atan2` ≈ 几万周期 ≈ 几十微秒。
可接受，但如果目标数上千就要优化。

**优化手段**：

| 手段 | 说明 |
|---|---|
| 查表（LUT） | 预计算 0~360° 的 sin/cos，用角度直接索引 |
| 多项式近似 | 用泰勒/切比雪夫逼近，精度可控 |
| SIMD（单指令多数据，一次算 4 个） | 需要硬件与编译器支持，实现复杂 |
| 减少调用 | 缓存不变的值（如每帧只算一次相机矩阵）✓ |

本项目用的是最后一条：**每帧只在 `camMakeMatrix` 里算一次**，
之后所有投影都是矩阵乘法（只有加减乘）。

## 坑七：`tan(FOV/2)` 在 FOV→90° 附近

```cpp
float t = tanf(fov * 0.5f * DEG2RAD);
```

| FOV | t = tan(FOV/2) |
|---|---|
| 60° | 0.577 |
| 90° | 1.0 |
| 120° | 1.732 |
| 170° | 11.43 |
| 179° | 114.6 |
| 180° | 无穷 |

FOV 越接近 180°，t 越大，除法后偏移越小（视野越广）——符合直觉。
但 FOV=180 会除零，所以本项目限制 `FOV < 179`。

## 坑八：符号约定不一致

不同引擎的坐标系不同：

| 引擎 | 上方向 | 前方向 | 手性 |
|---|---|---|---|
| UE4 | +Z | +X | 左手 |
| Unity | +Y | +Z | 左手 |
| OpenGL | +Y | -Z | 右手 |

本项目是 UE4 约定。如果哪天要适配 Unity 游戏，
**所有三角函数前面的符号都要改**。

这也是为什么"焦距微调"滑块那么有用——
坐标系细节搞错时，调系数能临时救场（虽然不优雅）。

## 动手：三角函数验证器

```cpp
#include <cstdio>
#include <cmath>
#include <cassert>
#include <initializer_list>   // for (float fov : {…}) 需要它

constexpr float PI = 3.14159265358979323846f;
constexpr float D2R = PI / 180.0f;
constexpr float R2D = 180.0f / PI;

struct Rot { float P, Y; };

// 方向 → 角度（本项目算法）
Rot DirToRot(float x, float y, float z) {
    float h = sqrtf(x*x + y*y);
    return { atan2f(z, h) * R2D, atan2f(y, x) * R2D };
}

int main(void) {
    printf("=== 1. atan vs atan2 象限 ===\n");
    float pairs[][2] = {{1,1}, {-1,1}, {-1,-1}, {1,-1}};
    const char* names[] = {"右上", "左上", "左下", "右下"};
    for (int i = 0; i < 4; i++) {
        float dx = pairs[i][0], dy = pairs[i][1];
        float a1 = atanf(dy/dx) * R2D;
        float a2 = atan2f(dy, dx) * R2D;
        printf("%s(%.0f,%.0f): atan=%7.1f  atan2=%7.1f  %s\n",
               names[i], dx, dy, a1, a2,
               fabsf(a1-a2) < 0.01f ? "" : "← 不同！");
    }

    printf("\n=== 2. 垂直方向不除零 ===\n");
    printf("atan2(1, 0) = %.1f 度（atan(1/0) 会崩）\n", atan2f(1, 0) * R2D);

    printf("\n=== 3. 角度环绕 ===\n");
    auto norm = [](float d) {
        while (d > 180) d -= 360;
        while (d <= -180) d += 360;
        return d;
    };
    printf("350 → 10   原始差=%7.1f  归一化=%6.1f\n", 10-350.0f, norm(10-350));
    printf("-170 → 170 原始差=%7.1f  归一化=%6.1f\n", 170+170.0f, norm(170-(-170)));

    printf("\n=== 4. acos 的 nan 风险 ===\n");
    float bad = 1.0000001f;                 // 浮点误差产生
    printf("acos(1.0000001) = %f\n", acosf(bad));
    printf("acos(clamp(...))= %f\n", acosf(fminf(1.0f, bad)));

    printf("\n=== 5. tan(FOV/2) ===\n");
    for (float fov : {60, 90, 120, 170, 179})
        printf("FOV=%3.0f  t=%.3f\n", fov, tanf(fov * 0.5f * D2R));

    printf("\n=== 6. 往返一致性 ===\n");
    float dirs[][3] = {{1,0,0},{0,1,0},{1,1,0},{3,4,5},{-1,0,0},{0,0,1}};
    for (auto& d : dirs) {
        Rot r = DirToRot(d[0], d[1], d[2]);
        // 反推方向
        float cp = cosf(r.P*D2R), sp = sinf(r.P*D2R);
        float cy = cosf(r.Y*D2R), sy = sinf(r.Y*D2R);
        float bx = cp*cy, by = cp*sy, bz = sp;
        float len = sqrtf(d[0]*d[0]+d[1]*d[1]+d[2]*d[2]);
        float dot = (bx*d[0] + by*d[1] + bz*d[2]) / len;
        printf("(%2.0f,%2.0f,%2.0f) → P=%6.1f Y=%6.1f  还原点积=%.6f\n",
               d[0],d[1],d[2], r.P, r.Y, dot);
        assert(fabsf(dot - 1.0f) < 1e-4f);     // 方向必须一致
    }
    printf("\n全部通过\n");
    return 0;
}
```

六项验证：象限、除零、环绕、nan、tan 曲线、往返一致。

## 课后习题

### 习题 56.1 `atan` vs `atan2` 象限对比（★★）

**任务要求**：对四个象限的点，分别用 `atan(dy/dx)` 和 `atan2(dy, dx)` 算角度，
验证 `atan` 丢失象限信息、`atan2` 正确。

**参考实现**：

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

constexpr float RAD2DEG = 57.29577951308232f;

int main() {
    struct { float dx, dy; } pts[] = {{1,1}, {-1,1}, {-1,-1}, {1,-1}};
    for (auto p : pts) {
        float a1 = atanf(p.dy / p.dx) * RAD2DEG;   // 只有 -90~90
        float a2 = atan2f(p.dy, p.dx) * RAD2DEG;   // 区分四象限，-180~180
        printf("(%+.0f,%+.0f): atan=%7.1f  atan2=%7.1f\n", p.dx, p.dy, a1, a2);
    }
    // 第三象限 (-1,-1)：atan 给 45，atan2 给 -135
    assert(fabsf(atanf(-1.0f / -1.0f) * RAD2DEG - 45.0f) < 0.1f);
    assert(fabsf(atan2f(-1, -1) * RAD2DEG - (-135.0f)) < 0.1f);
    // atan2(1,0)=90，不除零
    assert(fabsf(atan2f(1, 0) * RAD2DEG - 90.0f) < 0.1f);
    printf("习题 56.1 全部通过\n");
    return 0;
}
```

**验证断言**：`(-1,-1)` 时 `atan` 得 `45`（错），`atan2` 得 `-135`（对）；`atan2(1,0)=90` 不除零。

> [!warning] 为什么必须用 atan2
> `dy/dx` 丢失符号信息：(1,1) 和 (-1,-1) 的商都是 1，但方向相差 180°。
> `atan2(dy, dx)` 接收两个参数，能区分四个象限，且 `dx=0` 时不除零。

### 习题 56.2 角度归一化到 (-180, 180]（★★）

**任务要求**：实现 `normalize_angle(deg)`，把任意角度归一化到 `(-180, 180]`。

**参考实现**：

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

float normalize_angle(float d) {
    while (d >  180.0f) d -= 360.0f;
    while (d <= -180.0f) d += 360.0f;
    return d;
}

int main() {
    assert(fabsf(normalize_angle(350) - (-10)) < 0.01f);
    assert(fabsf(normalize_angle(190) - (-170)) < 0.01f);
    assert(fabsf(normalize_angle(-190) - 170) < 0.01f);
    assert(fabsf(normalize_angle(720) - 0) < 0.01f);
    assert(fabsf(normalize_angle(180) - 180) < 0.01f);
    printf("习题 56.2 全部通过\n");
    return 0;
}
```

> [!note] 归一化的用途
> 角度是周期的：`350°` 和 `-10°` 是同一方向。本项目自瞄里"转向目标"时，
> 先归一化角度差，保证走**最短路**（第 47 章 `归一角差` 就是这个原理）。
