# 第 46 章 · 矩阵与线性变换

> [!abstract] 本章目标
> 理解矩阵为什么能表示变换，会做矩阵乘法，
> 并知道为什么 3D 图形用 4×4 而不是 3×3。

> [!note] 承上
> 上一章的向量能表示"方向和大小"。
> 本章的**矩阵**能表示"变换"——旋转、缩放、平移。

## 先看一个矩阵能干什么

```cpp
// 把点 (1, 0, 0) 绕 Z 轴转 90 度
Vec3 p = {1, 0, 0};
Matrix rot = RotationZ(90度);
Vec3 result = rot * p;      // (0, 1, 0)
```

一个矩阵，一次性表达"旋转 + 缩放 + 平移"。
整个 3D 渲染的数学核心就是这个。

## 矩阵是什么

一个 m×n 的**数字表格**。3D 图形里主要用 4×4：

```cpp
struct Matrix {
    float M[4][4];
};
```

本项目就是这么定义的（`VectorTools.h`）。

## 矩阵 × 向量

规则：**结果的第 i 个分量 = 矩阵第 i 行 · 向量**（点积）。

```
┌              ┐   ┌   ┐   ┌                                       ┐
│ m00 m01 m02  │   │ x │   │ m00*x + m01*y + m02*z                 │
│ m10 m11 m12  │ × │ y │ = │ m10*x + m11*y + m12*z                 │
│ m20 m21 m22  │   │ z │   │ m20*x + m21*y + m22*z                 │
└              ┘   └   ┘   └                                       ┘
```

```cpp
Vec3 Mul(const Matrix &m, const Vec3 &v) {
    return {
        m.M[0][0]*v.x + m.M[0][1]*v.y + m.M[0][2]*v.z,
        m.M[1][0]*v.x + m.M[1][1]*v.y + m.M[1][2]*v.z,
        m.M[2][0]*v.x + m.M[2][1]*v.y + m.M[2][2]*v.z
    };
}
```

### 单位矩阵：什么都不做

```
┌         ┐
│ 1 0 0 0 │
│ 0 1 0 0 │     乘以任何向量 = 原向量
│ 0 0 1 0 │
│ 0 0 0 1 │
└         ┘
```

### 缩放矩阵

```
┌         ┐
│ 2 0 0 0 │     x 放大 2 倍
│ 0 2 0 0 │     y 放大 2 倍
│ 0 0 2 0 │     z 放大 2 倍
│ 0 0 0 1 │
└         ┘
```

把 (1,2,3) 变成 (2,4,6)。

## 矩阵 × 矩阵：变换的组合

**最重要的一条性质**：矩阵乘法 = 变换的复合。

**先明确一个前提**：本节讲解统一采用 **列向量约定**（点写成一列、矩阵在左：`v' = M · v`），
这也是多数教材和 OpenGL 的写法。在这个约定下，复合时**右边的矩阵先作用**：

```
先旋转再平移  →  v' = 平移矩阵 × 旋转矩阵 × v
                       └──── 旋转先作用 ────┘
```

> [!note] 本项目源码用的是另一种约定，顺序会"看起来相反"
> 本项目的动手 demo 和源码用**行向量约定**（`v' = v · M`，平移写在第 4 行）：
> 同一个"先旋转再平移"会写成 `旋转矩阵 × 平移矩阵`（旋在左）。
> **这是约定不同，不是结论矛盾**——两套约定互为转置（见本节末"行主序 vs 列主序"）。
>
> 为避免混淆，本卷统一规则：
> - **讲数学时**：用列向量约定（`M_parent × M_local`，右先作用）；
> - **看 demo / 源码时**：用行向量约定，**以代码注释里写的"谁先作用"为准**。
> 下面的动手 demo 注释已逐行标注。

规则：**结果[i][j] = A 第 i 行 · B 第 j 列**

```cpp
Matrix MatrixMulti(const Matrix& m1, const Matrix& m2) {
    Matrix result = {};
    for (int i = 0; i < 4; ++i)
        for (int j = 0; j < 4; ++j)
            for (int k = 0; k < 4; ++k)
                result.M[i][j] += m1.M[i][k] * m2.M[k][j];
    return result;
}
```

这就是本项目 `variable.h` 里的实现（三重循环，64 次乘法）。

> [!danger] 矩阵乘法不满足交换律
> ```
> A × B ≠ B × A
> ```
> "先旋转后平移" 和 "先平移后旋转" 结果完全不同：
> - 先旋转后平移：物体绕自己原点转，再移到某处
> - 先平移后旋转：物体移到某处，再绕世界原点转（会被甩出去）
>
> **顺序错了，画面就完全不对。**

## 为什么是 4×4 而不是 3×3

3×3 能表示旋转和缩放，但**不能表示平移**。

原因是：矩阵乘法本质是"各分量的线性组合"，
而平移要加一个**常数项**：

```
平移：x' = x + 5        ← 这个 +5 是常数，3×3 表达不了
```

解法：**齐次坐标**。给向量加第 4 个分量 w：

```
点 (x, y, z)  →  (x, y, z, 1)
方向 (x,y,z)  →  (x, y, z, 0)
```

然后平移就能塞进矩阵第 4 列：

```
┌            ┐   ┌   ┐   ┌         ┐
│ 1 0 0  5   │   │ x │   │ x + 5   │
│ 0 1 0  6   │ × │ y │ = │ y + 6   │
│ 0 0 1  7   │   │ z │   │ z + 7   │
│ 0 0 0  1   │   │ 1 │   │   1     │
└            ┘   └   ┘   └         ┘
```

> [!note] w=1 是点，w=0 是方向
> 点乘 4×4 平移矩阵会移动；
> 方向（w=0）乘同样的矩阵**不会移动**——因为第 4 列被 0 乘没了。
>
> 这正好符合直觉："方向"没有位置，平移对它无意义。

## 4×4 矩阵的四块含义

```
┌───────────────┬────────┐
│               │        │
│   3×3 线性变换 │  平移   │
│  (旋转+缩放)   │        │
│               │        │
├───────────────┼────────┤
│  0  0  0      │   1    │
└───────────────┴────────┘
     ↑              ↑
  旋转/缩放       位置
```

本项目提取位置：

```cpp
inline Vector3A MarixToVector(const Matrix& matrix) {
    return Vector3A(matrix.M[3][0], matrix.M[3][1], matrix.M[3][2]);
}
```

`M[3][0..2]` 就是第 4 行（在行主序存储里是平移分量）。

> [!warning] 图和代码的"平移位置"看起来不一样，其实是两套约定
> 上面的四块含义图，平移画在**右上角（第 4 列）**，这对应"**列向量约定**"
> （点写成一列、矩阵在左：`v' = M × v`）——多数教材、OpenGL 用这套。
> 本项目源码却把平移放在**第 4 行** `M[3][0..2]`，这对应"**行向量约定**"
> （点写成一排、矩阵在右：`v' = v × M`）。
>
> **两套约定的矩阵互为转置。** 本项目内部是自洽的：
> `TransformToMatrix` 把平移写在 `M[3][0..2]`，`MarixToVector` 也从 `M[3][0..2]` 读，
> 首尾一致，所以能正常工作。你只要记住：**读本项目源码时，平移在第 4 行**。
>
> 本教程讲"变换复合顺序"时统一用**列向量约定**（更符合直觉），
> 所以你会看到"先旋转再平移 = 平移矩阵 × 旋转矩阵"这类说法——
> 那是**数学解释**；而源码里的乘法顺序可能"看起来相反"，是**存储约定**造成的，两者并不冲突。

## 行主序 vs 列主序

矩阵在内存里是连续的 16 个 float，有两种"读法"：

| 存储方式 | `M[i][j]` 的含义 | 谁用 |
|---|---|---|
| **行主序**（Row-major） | 第 i 行第 j 列 | DirectX、多数 C 代码 |
| **列主序**（Column-major） | 第 j 列第 i 行 | OpenGL、glm |

**同一个数组，两种解释得到的是转置矩阵。**

```cpp
float M[4][4];
// 行主序：M[row][col]
// 列主序：M[col][row]
```

> [!warning] 这是 3D 数学最常见的错误来源
> 症状：物体旋转方向反了、平移变成了旋转。
> 判断方法：用单位矩阵测试，或者直接看平移分量在哪。
>
> **本项目比较特殊：用了两种矩阵表示，别搞混。**
> - **`Matrix` 结构体**（`float M[4][4]`，二维数组）：按 C 默认的**行主序**，平移在 `M[3][0..2]`。
> - **`matrix[16]` 一维数组**（`camMakeMatrix` 构建，第 49/50 章用）：采用**列主序存储**（`matrix[row + col*4]`），但表达的仍是"行布局"的数学含义。
>
> 源码注释把它写成"**行布局(列主序存储)**"——**行布局说的是数学含义，列主序存储说的是数组下标算法**，两者不矛盾。第 49 章会展开讲一维数组那套。

## 变换的逆

"把变换撤销"的矩阵叫逆矩阵：

```
M × M⁻¹ = I（单位矩阵）
```

用途：
- 世界坐标 → 局部坐标（乘逆矩阵）
- 相机变换（视图矩阵就是相机世界矩阵的逆，第 49 章）

本项目没算过逆矩阵（用的是直接构造法），但第 49 章推导视图矩阵时会用到这个概念。

## 行列式与正交矩阵（了解）

- **行列式**：矩阵对体积的缩放倍数。为 0 表示"压扁了"（不可逆）
- **正交矩阵**：旋转矩阵都是正交的，它的逆 = 它的转置（省一大笔计算）

```cpp
// 旋转矩阵的逆 = 转置
Matrix Transpose(const Matrix &m) {
    Matrix r;
    for (int i = 0; i < 4; i++)
        for (int j = 0; j < 4; j++)
            r.M[i][j] = m.M[j][i];
    return r;
}
```

## 动手：验证矩阵基本性质

```cpp
#include <cstdio>
#include <cmath>
#include <cassert>

struct Vec3 { float x=0,y=0,z=0; };
struct Mat4 { float M[4][4] = {}; };

Mat4 Identity() {
    Mat4 m;
    for (int i = 0; i < 4; i++) m.M[i][i] = 1.0f;
    return m;
}

Mat4 Translation(float x, float y, float z) {
    Mat4 m = Identity();
    m.M[3][0] = x; m.M[3][1] = y; m.M[3][2] = z;
    return m;
}

Mat4 Scale(float s) {
    Mat4 m = Identity();
    m.M[0][0] = m.M[1][1] = m.M[2][2] = s;
    return m;
}

Mat4 Mul(const Mat4 &a, const Mat4 &b) {
    Mat4 r;
    for (int i=0;i<4;i++) for (int j=0;j<4;j++) for (int k=0;k<4;k++)
        r.M[i][j] += a.M[i][k] * b.M[k][j];
    return r;
}

Vec3 ApplyPoint(const Mat4 &m, const Vec3 &v) {
    return {
        m.M[0][0]*v.x + m.M[0][1]*v.y + m.M[0][2]*v.z + m.M[3][0],
        m.M[1][0]*v.x + m.M[1][1]*v.y + m.M[1][2]*v.z + m.M[3][1],
        m.M[2][0]*v.x + m.M[2][1]*v.y + m.M[2][2]*v.z + m.M[3][2]
    };
}

int main(void) {
    // 1. 单位矩阵不改变向量
    Vec3 p{1,2,3};
    Vec3 r0 = ApplyPoint(Identity(), p);
    assert(r0.x==1 && r0.y==2 && r0.z==3);

    // 2. 平移
    Vec3 r1 = ApplyPoint(Translation(10,20,30), p);
    printf("平移后: (%.0f,%.0f,%.0f)\n", r1.x, r1.y, r1.z);   // (11,22,33)

    // 3. 缩放
    Vec3 r2 = ApplyPoint(Scale(2), p);
    printf("缩放后: (%.0f,%.0f,%.0f)\n", r2.x, r2.y, r2.z);   // (2,4,6)

    // 4. 顺序很重要：两种顺序结果不同
    // 本 demo 用"平移写在第 4 行"的行向量约定。为便于对照，
    // 结论直接以实测输出为准（下面注释就是程序真实输出）：
    Vec3 a = ApplyPoint(Mul(Translation(10,0,0), Scale(2)), p);   // 等效"先平移后缩放" → (22,4,6)
    Vec3 b = ApplyPoint(Mul(Scale(2), Translation(10,0,0)), p);   // 等效"先缩放后平移" → (12,4,6)
    printf("T*S: (%.0f,%.0f,%.0f)\n", a.x, a.y, a.z);   // (22,4,6)
    printf("S*T: (%.0f,%.0f,%.0f)\n", b.x, b.y, b.z);   // (12,4,6)
    assert(a.x != b.x);    // ★ 证明不可交换

    printf("全部通过\n");
    return 0;
}
```

关键观察：`T*S` 得到 (22,4,6)，`S*T` 得到 (12,4,6)。
**顺序不同结果不同**，这就是矩阵乘法不可交换的实证。

## 课后习题

### 习题 46.1 验证矩阵乘法不可交换（★★）

**任务要求**：构造平移矩阵 `T` 和缩放矩阵 `S`，对同一点分别算 `T*S` 和 `S*T`，
断言两者结果**不同**（证明不可交换）。

**参考实现**（列向量约定，`v' = M * v`）：

```cpp
#include <cstdio>
#include <cassert>
#include <cmath>

struct Mat4 { float m[4][4] = {}; };

Mat4 Identity() {
    Mat4 r;
    for (int i = 0; i < 4; i++) r.m[i][i] = 1.0f;
    return r;
}
Mat4 Translation(float tx, float ty, float tz) {
    Mat4 r = Identity();
    r.m[0][3] = tx; r.m[1][3] = ty; r.m[2][3] = tz;
    return r;
}
Mat4 Scale(float s) {
    Mat4 r = Identity();
    r.m[0][0] = s; r.m[1][1] = s; r.m[2][2] = s;
    return r;
}
Mat4 Mul(const Mat4& a, const Mat4& b) {
    Mat4 r;
    for (int i=0;i<4;i++) for (int j=0;j<4;j++)
        for (int k=0;k<4;k++) r.m[i][j] += a.m[i][k]*b.m[k][j];
    return r;
}
void MulVec(const Mat4& a, const float v[4], float out[4]) {
    for (int i=0;i<4;i++) {
        out[i] = 0;
        for (int k=0;k<4;k++) out[i] += a.m[i][k]*v[k];
    }
}

int main() {
    Mat4 T = Translation(10, 0, 0);   // 平移
    Mat4 S = Scale(2);                // 缩放
    float p[4] = {1, 0, 0, 1};        // 一个点

    float ts[4], st[4];
    MulVec(Mul(T, S), p, ts);          // T*S：先缩放再平移
    MulVec(Mul(S, T), p, st);          // S*T：先平移再缩放
    printf("T*S -> (%.1f,%.1f,%.1f)  S*T -> (%.1f,%.1f,%.1f)\n", ts[0],ts[1],ts[2], st[0],st[1],st[2]);

    // T*S：先缩放 (1→2)，再平移 → (12,0,0)
    assert(std::fabs(ts[0] - 12.0f) < 0.01f);
    // S*T：先平移 (1→11)，再缩放 → (22,0,0)
    assert(std::fabs(st[0] - 22.0f) < 0.01f);
    assert(std::fabs(ts[0] - st[0]) > 0.01f);   // ★ 不可交换
    printf("习题 46.1 全部通过\n");
    return 0;
}
```

**验证断言**：`T*S` 得 `12`，`S*T` 得 `22`，两者不等——证明矩阵乘法**不满足交换律**。

> [!note] 顺序决定结果
> "先缩放再平移"和"先平移再缩放"完全不同。这就是本章强调的**复合顺序**——
> 骨骼变换链、视图矩阵里顺序错了，画面就全错。

### 习题 46.2 w=1 vs w=0（★★）

**任务要求**：用同一个平移矩阵变换 `(1,0,0,1)`（点）和 `(1,0,0,0)`（方向），
观察：点被平移、方向**不被平移**。

**参考实现**：

```cpp
#include <cstdio>
#include <cassert>
#include <cmath>

struct Mat4 { float m[4][4] = {}; };
Mat4 Translation(float tx, float ty, float tz) {
    Mat4 r; for (int i=0;i<4;i++) r.m[i][i]=1.0f;
    r.m[0][3]=tx; r.m[1][3]=ty; r.m[2][3]=tz;
    return r;
}
void MulVec(const Mat4& a, const float v[4], float out[4]) {
    for (int i=0;i<4;i++) { out[i]=0; for (int k=0;k<4;k++) out[i]+=a.m[i][k]*v[k]; }
}

int main() {
    Mat4 T = Translation(5, 6, 7);
    float point[4]   = {1, 0, 0, 1};   // 点（w=1）
    float dir[4]     = {1, 0, 0, 0};   // 方向（w=0）
    float op[4], od[4];
    MulVec(T, point, op);
    MulVec(T, dir, od);
    printf("点   -> (%.0f,%.0f,%.0f)  方向 -> (%.0f,%.0f,%.0f)\n", op[0],op[1],op[2], od[0],od[1],od[2]);
    assert(std::fabs(op[0]-6.0f)<0.01f && std::fabs(op[1]-6.0f)<0.01f && std::fabs(op[2]-7.0f)<0.01f);  // 点被平移
    assert(std::fabs(od[0]-1.0f)<0.01f && std::fabs(od[1])<0.01f && std::fabs(od[2])<0.01f);          // 方向不变
    printf("习题 46.2 全部通过\n");
    return 0;
}
```

> [!tip] 为什么这样设计
> 平移矩阵第 4 列是平移量。方向 `w=0` 时，第 4 列被 0 乘没了——所以**平移对方向无意义**，
> 这正是齐次坐标 `w` 分量的用途。

## 常见坑排查表

| 症状 | 最可能的原因 | 解法 |
|---|---|---|
| 物体**缩放后再平移，位置不对** | 复合顺序反了（`T*S` vs `S*T`）| 列向量约定下，**右边先作用**：想要"先缩放后平移"写 `T*S` |
| 平移矩阵写在第 4 行不生效 | 用了列向量约定却在第 4 行放平移 | 列向量约定平移在**第 4 列**（`m[0][3]`）；行向量才在第 4 行 |
| 两个矩阵相乘结果**全是 0** | 矩阵没初始化（`float m[4][4];` 是垃圾值）| 用 `float m[4][4] = {};` 零初始化 |
| 旋转看起来**是镜像** | 用了转置矩阵 | `Mul` 顺序或 `m[i][j]/m[j][i]` 写反了 |

> [!danger] 顺序错了画面全错，但不会崩
> 矩阵顺序是**最隐蔽的坑**：程序正常跑、不报错，只是画面不对。
> 定位方法：拿一个已知点，手算两种顺序的预期结果，对比程序输出。

## 自动化单元自测

> 对应本章核心单元：Mul(矩阵×向量)、MatrixMulti(矩阵×矩阵)、MarixToVector(取平移)。

### 测试脚本（保存为 ch46_test.cpp）

```cpp
// ch46_test.cpp —— 第46章矩阵单元自测（自包含）
#include <cstdio>
#include <cassert>
#include <cmath>

// ===== 对齐本项目 VectorTools.h 的精简定义 =====
struct Vec3 {
    float x = 0, y = 0, z = 0;
    Vec3() = default;
    Vec3(float a, float b, float c) : x(a), y(b), z(c) {}
};
struct Matrix { float M[4][4]; };

// ===== 被测单元（抄自本章正文）=====
Vec3 Mul(const Matrix &m, const Vec3 &v) {
    return {
        m.M[0][0]*v.x + m.M[0][1]*v.y + m.M[0][2]*v.z,
        m.M[1][0]*v.x + m.M[1][1]*v.y + m.M[1][2]*v.z,
        m.M[2][0]*v.x + m.M[2][1]*v.y + m.M[2][2]*v.z
    };
}
Matrix MatrixMulti(const Matrix& m1, const Matrix& m2) {
    Matrix result = {};
    for (int i = 0; i < 4; ++i)
        for (int j = 0; j < 4; ++j)
            for (int k = 0; k < 4; ++k)
                result.M[i][j] += m1.M[i][k] * m2.M[k][j];
    return result;
}
Vec3 MarixToVector(const Matrix& matrix) {
    return Vec3(matrix.M[3][0], matrix.M[3][1], matrix.M[3][2]);
}
Matrix Identity() {
    Matrix m = {};
    for (int i = 0; i < 4; i++) m.M[i][i] = 1.0f;
    return m;
}
Matrix Scale(float s) {
    Matrix m = Identity();
    m.M[0][0] = m.M[1][1] = m.M[2][2] = s;
    return m;
}
Matrix Translate(float tx, float ty, float tz) {
    Matrix m = Identity();
    m.M[3][0] = tx; m.M[3][1] = ty; m.M[3][2] = tz;   // 行主序：平移放第 4 行
    return m;
}

static bool near(float a, float b, float eps = 1e-4f) { return std::fabs(a-b) < eps; }

int main() {
    // ===== Arrange =====
    Matrix I = Identity();
    Matrix S = Scale(2.0f);
    Matrix T = Translate(5.0f, 6.0f, 7.0f);

    // ===== Act + Assert：正常路径 =====
    Vec3 v = Mul(I, Vec3(1, 2, 3));
    assert(near(v.x,1) && near(v.y,2) && near(v.z,3));
    std::printf("[PASS] 单位矩阵恒等\n");

    Vec3 sv = Mul(S, Vec3(1, 2, 3));
    assert(near(sv.x,2) && near(sv.y,4) && near(sv.z,6));
    std::printf("[PASS] 缩放矩阵\n");

    Vec3 pos = MarixToVector(T);
    assert(near(pos.x,5) && near(pos.y,6) && near(pos.z,7));
    std::printf("[PASS] MarixToVector 取平移\n");

    // 矩阵乘法 = 变换复合（S*T 与 T*S 不同）
    // 行向量约定(v'=v·M)：平移在第 4 行；复合时"左矩阵先作用"
    Vec3 st = MarixToVector(MatrixMulti(S, T));   // S·T：缩放无平移分量 → 平移仍是 5,6,7
    Vec3 ts = MarixToVector(MatrixMulti(T, S));   // T·S：T 的平移被 S 放大 → 10,12,14
    assert(near(st.x, 5)  && near(st.y, 6)  && near(st.z, 7));
    assert(near(ts.x, 10) && near(ts.y, 12) && near(ts.z, 14));
    std::printf("[PASS] 矩阵乘法不可交换（S*T != T*S）\n");

    // ===== 反向异常路径 =====
    Matrix Z = {};
    Vec3 zv = Mul(Z, Vec3(9, 9, 9));
    assert(near(zv.x,0) && near(zv.y,0) && near(zv.z,0));
    std::printf("[PASS] 反向: 零矩阵输出零向量\n");

    Matrix S9 = Scale(9.0f);
    Vec3 s9p = MarixToVector(S9);
    assert(near(s9p.x,0) && near(s9p.y,0) && near(s9p.z,0));
    std::printf("[PASS] 反向: 纯缩放矩阵平移分量为 0\n");

    std::printf("\n第46章 全部断言通过\n");
    return 0;
}
