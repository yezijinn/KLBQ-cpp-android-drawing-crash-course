## 先看一个具体问题

你在世界坐标 `(100, 200, 50)`，敌人在 `(400, 600, 50)`。
问：敌人在你的哪个方向？有多远？

> [!note] 关于坐标单位
> 本项目沿用 UE4（虚幻引擎）的约定：**世界坐标的单位是厘米**。
> 所以 `(100, 200, 50)` 指的是"离原点 1 米、2 米、半米"的位置。
> 本卷只关心向量的运算规则，单位到第 52 章讲剔除时才会真正用到，
> 现在你只要知道"数就是厘米"即可。

```cpp
Vec3 me   = {100, 200, 50};
Vec3 enemy = {400, 600, 50};

Vec3 dir = enemy - me;        // (300, 400, 0)  方向 + 距离
float dist = dir.Length();    // 500             距离
Vec3 norm = dir / dist;       // (0.6, 0.8, 0)   纯方向（单位向量）
```

三个操作：**减法得方向、求模得距离、除法得单位方向**。
整个 ESP 和自瞄系统，反复用的就是这三招。

## 补一节：三角函数与角度（本卷必备）

> [!warning] 为什么这里要先补三角函数
> 本卷后面（尤其第 47、49、50、56 章）会大量使用 `sin`、`cos`、`tan`、`atan2`。
> 这些是**高中知识**，但如果你忘了、或从没学过，这里用**大白话补一遍**，够用即可。
> 只需要 5 分钟看懂下面几段，不用背。

**① 直角三角形的三条边**

```
        │╲
   对边 │ ╲  斜边
（对θ） │  ╲
        │ θ)╲
        └─────
          邻边（挨着 θ）
```

**② 三个函数就是"两条边的比值"**（θ 是某个锐角）

| 函数 | 等于 | 记忆 |
|---|---|---|
| `sin(θ)` | 对边 / 斜边 | "正弦 = 对 / 斜" |
| `cos(θ)` | 邻边 / 斜边 | "余弦 = 邻 / 斜" |
| `tan(θ)` | 对边 / 邻边 | "正切 = 对 / 邻" |

已知**角度**求**比值**，用上面三个；反过来**已知比值求角度**，用反函数 `asin/acos/atan`。

**③ 度 vs 弧度（两套角度单位）**

| 单位 | 一圈是 | 用在哪 |
|---|---|---|
| **度**（°） | 360° | 人看、游戏内存里存的 |
| **弧度**（rad） | 2π ≈ 6.28 | C 标准库的 `sinf/cosf/atan2f` 用 |

换算：**1 弧度 = 180/π 度**，所以"弧度 × 180/π = 度"、"度 × π/180 = 弧度"。
（第 56 章会把这里的坑讲透；现在只要记住这个换算，看到代码里 `* 180.0f / PI` 就知道是"弧度转度"。）

**④ 一句话用途**

本卷用到它们，都是为了"**把方向（向量）和角度（Pitch/Yaw）互相换算**"——
比如"敌人在我右前方 30°"这种判断。具体到第 47 章会展开。

## 向量是什么

两种理解，都成立：

| 视角 | 含义 | 例子 |
|---|---|---|
| 几何 | 有方向、有长度的箭头 | 从 A 指向 B |
| 代数 | 一组有序的数 | `(3, 4, 0)` |

本项目用后者存储，用前者理解。

```cpp
struct Vec3 {
    float x, y, z;
};
```

## 四种基础运算

### 1. 加减法（平移）

```cpp
Vec3 a = {1, 2, 3}, b = {10, 20, 30};
Vec3 c = a + b;      // (11, 22, 33)
Vec3 d = b - a;      // (9, 18, 27)
```

几何意义：`b - a` 是"从 a 指向 b 的箭头"。

> [!note] 位置 - 位置 = 方向；位置 + 方向 = 位置
> ```cpp
> Vec3 敌人相对我 = 敌人位置 - 我的位置;    // 方向
> Vec3 我前方的点 = 我的位置 + 朝向 * 100;  // 位置
> ```
> 位置 + 位置 没有意义（两个点相加是什么？）

### 2. 数乘（缩放）

```cpp
Vec3 a = {1, 2, 3};
Vec3 b = a * 2.5f;    // (2.5, 5, 7.5)
```

改变长度，方向不变（负数则反向）。

### 3. 点积（Dot Product）★最重要

```cpp
float Dot(const Vec3 a, const Vec3 b) {
    return a.x*b.x + a.y*b.y + a.z*b.z;
}
```

结果是一个**数**，不是向量。

> [!tip] 点积在量什么
> 一句话：**点积衡量"两个方向有多一致"**。
> - 同向 → 点积最大（正数）
> - 垂直 → 点积为 0（"完全不搭边"）
> - 反向 → 点积最小（负数）
>
> 所以自瞄里用 `Dot(朝向, 到目标的方向)` 判断"目标在不在我前方"——
> 点积越大，目标越正对我。

它的几何意义：

```
Dot(a, b) = |a| × |b| × cos(θ)
```

θ 是两向量的夹角。推论：

| 情况 | Dot 值 | 含义 |
|---|---|---|
| 同向 | 正的最大 | 夹角 0° |
| 垂直 | **0** | 夹角 90° |
| 反向 | 负的最大 | 夹角 180° |

**单位化后，Dot 就是 cos(θ)**：

```cpp
constexpr float PI = 3.14159265358979323846f;   // 先定义 π，C 标准库的 acosf 返回弧度

float cosAngle = Dot(a.Normalized(), b.Normalized());
cosAngle = std::clamp(cosAngle, -1.0f, 1.0f);   // ★ 必须 clamp，否则可能得到 NaN（第 56 章详解）
float angle = acosf(cosAngle) * 180.0f / PI;    // 弧度 → 角度
```

> [!note] 为什么要乘 180/π
> `acosf` 返回的是**弧度**，而本项目里角度都用**度**。1 弧度 = 180/π 度。
> 度与弧度的换算、以及 `acos` 为什么要 clamp，第 56 章会系统讲，这里先照抄。
> （`std::clamp` 定义在 `<algorithm>` 头文件里，用之前要 `#include <algorithm>`。）

> [!tip] 本项目里的两处点积用法
> 1. **判断目标在不在视野内**：`Dot(朝向, 到目标的方向) > cos(FOV/2)`
> 2. **判断在身前还是身后**：`Dot > 0` 在身前，`< 0` 在身后

本项目用的是角度比较（第 56 章会说明为什么不用点积），但原理相同。

### 4. 叉积（Cross Product）

```cpp
Vec3 Cross(const Vec3 a, const Vec3 b) {
    return {
        a.y*b.z - a.z*b.y,
        a.z*b.x - a.x*b.z,
        a.x*b.y - a.y*b.x
    };
}
```

结果是**垂直于 a 和 b 的向量**，长度 = |a||b|sin(θ)。

上面这个公式是叉积的**统一代数定义**，本身跟坐标系手系无关——
你给 `a`、`b` 代入具体的数字，它就算出唯一确定的结果。
**手系影响的不是公式，而是"结果朝哪边"的解读**：
同样的输入，在右手系里看是"朝上"，换个手系看可能就变成"朝下"。
所以实际用的时候，关键是**确定"谁叉乘谁"能得到你想要的基向量方向**，
这一点第 49 章推相机基向量（`up = forward × right`）时会具体演示。

用途：
- 求平面的法线（两个边向量的叉积）
- 判断左右（在 2D 里看 z 分量符号）
- 构建坐标系（已知前向量和上向量，叉积得右向量）

本项目没直接用叉积，但第 47 章构建旋转矩阵时会用到这个概念。

## 长度与归一化

**长度**（也叫"模"）= 向量箭头有多长，用勾股定理算（三维就是三个分量平方和开方）。
**归一化**（Normalize）= 把向量**长度变成 1、方向不变**，做法是每个分量都除以原长度。
归一化后得到的就是前面说的"单位向量"（长度恰好为 1），常用来表示"纯方向"。

```cpp
float Length(const Vec3 v) {
    return sqrtf(v.x*v.x + v.y*v.y + v.z*v.z);
}

Vec3 Normalized(const Vec3 v) {
    float len = Length(v);
    if (len < 1e-6f) return {0, 0, 0};     // ★ 必须防除零
    return {v.x/len, v.y/len, v.z/len};
}
```

> [!danger] 零向量归一化会除零
> `sqrtf(0) = 0` → 除以 0 → `inf` 或 `nan`。
> 这个 nan 会污染后续所有计算，最终表现为"画出来的线飞了"。
> 本项目里凡是除法都有保护：
> ```cpp
> float w = matrix[3]*obj.X + ...;
> if (w < 0.001f) return false;      // 防除零
> ```

## 距离

```cpp
float Dist(const Vec3 a, const Vec3 b) {
    return Length(b - a);
}

// 性能优化：比较距离时不开方
float DistSq(const Vec3 a, const Vec3 b) {
    Vec3 d = b - a;
    return d.x*d.x + d.y*d.y + d.z*d.z;
}
```

比较远近时，`DistSq` 就够了（平方是单调的），省一次 `sqrtf`。

本项目选目标时用的是**屏幕距离的平方**：

```cpp
const float 目标dx = rootScreen.X - px;
const float 目标距离 = 目标dx*目标dx + 目标dy*目标dy;   // 没开方
```

## Vec2：屏幕坐标

```cpp
struct Vec2 { float x, y; };
```

用法：
- 屏幕像素坐标（0,0 在左上角，y 向下）

## 动手：实现并验证向量库

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

struct Vec3 {
    float x = 0, y = 0, z = 0;
    Vec3() = default;
    Vec3(float x_, float y_, float z_) : x(x_), y(y_), z(z_) {}

    Vec3 operator+(const Vec3 &v) const { return {x+v.x, y+v.y, z+v.z}; }
    Vec3 operator-(const Vec3 &v) const { return {x-v.x, y-v.y, z-v.z}; }
    Vec3 operator*(float s) const { return {x*s, y*s, z*s}; }
    Vec3 operator/(float s) const { return {x/s, y/s, z/s}; }

    float Dot(const Vec3 &v) const { return x*v.x + y*v.y + z*v.z; }
    Vec3  Cross(const Vec3 &v) const {
        return {y*v.z - z*v.y, z*v.x - x*v.z, x*v.y - y*v.x};
    }
    float LengthSq() const { return x*x + y*y + z*z; }
    float Length() const { return sqrtf(LengthSq()); }
    Vec3  Normalized() const {
        float len = Length();
        return len < 1e-6f ? Vec3{} : (*this) / len;
    }
};

int main(void) {
    // 1. 方向 + 距离（开篇的例子）
    Vec3 me{100, 200, 50}, enemy{400, 600, 50};
    Vec3 dir = enemy - me;
    printf("方向=(%.0f,%.0f,%.0f) 距离=%.0f\n",
           dir.x, dir.y, dir.z, dir.Length());
    assert(fabsf(dir.Length() - 500.0f) < 0.001f);

    // 2. 归一化后长度必为 1
    Vec3 n = dir.Normalized();
    printf("单位方向=(%.2f,%.2f,%.2f) 模=%.6f\n", n.x, n.y, n.z, n.Length());
    assert(fabsf(n.Length() - 1.0f) < 1e-5f);

    // 3. 点积：垂直为 0
    Vec3 a{1,0,0}, b{0,1,0}, c{1,1,0};
    assert(a.Dot(b) == 0.0f);                      // 垂直
    assert(fabsf(a.Dot(a) - 1.0f) < 1e-6f);        // 自己点自己 = 长度平方

    // 4. 夹角
    float cosA = a.Dot(c.Normalized());
    printf("a 与 c 夹角 = %.1f 度\n", acosf(cosA) * 180.0f / 3.14159265f);

    // 5. 叉积：垂直且与两边都垂直
    Vec3 cr = a.Cross(b);
    printf("a×b = (%.0f,%.0f,%.0f)\n", cr.x, cr.y, cr.z);   // (0,0,1)
    assert(fabsf(cr.Dot(a)) < 1e-6f && fabsf(cr.Dot(b)) < 1e-6f);

    // 6. 零向量安全
    Vec3 zero{0,0,0};
    assert(zero.Normalized().LengthSq() == 0.0f);   // 不崩、不产生 nan
    printf("全部通过\n");
    return 0;
}
```

编译：`g++ -std=c++17 -Wall vec.cpp -o vec -lm`

**必须验证的 6 条**：距离 500、单位向量模为 1、垂直点积为 0、
夹角 45 度、叉积与两边垂直、零向量不产生 nan。

## 课后习题

### 习题 45.1 实现向量库并写断言（★★）

**任务要求**：实现 `Vec3` 及其 `Dot`/`Cross`/`Length`/`Normalized`，写满 6 项断言。

**参考实现**：

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

constexpr float EPS = 1e-6f;

struct Vec3 {
    float x = 0, y = 0, z = 0;
    Vec3() = default;
    Vec3(float a, float b, float c) : x(a), y(b), z(c) {}
    Vec3 operator+(const Vec3& v) const { return {x+v.x, y+v.y, z+v.z}; }
    Vec3 operator-(const Vec3& v) const { return {x-v.x, y-v.y, z-v.z}; }
    Vec3 operator*(float s)       const { return {x*s, y*s, z*s}; }
    float Dot(const Vec3& v)  const { return x*v.x + y*v.y + z*v.z; }
    Vec3  Cross(const Vec3& v) const {
        return {y*v.z - z*v.y, z*v.x - x*v.z, x*v.y - y*v.x};
    }
    float LengthSq() const { return x*x + y*y + z*z; }
    float Length()   const { return std::sqrt(LengthSq()); }
    Vec3 Normalized() const {
        float l = Length();
        return l < EPS ? Vec3{} : (*this) / l;   // ★ 防除零
    }
    Vec3 operator/(float s) const { return {x/s, y/s, z/s}; }
};
```

**验证断言**（接上面的 `Vec3` 定义，补齐头文件后可直接编译）：

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

int main() {
    // 1. 长度
    assert(std::fabs(Vec3(3,4,0).Length() - 5.0f) < 1e-4f);
    // 2. 点积（垂直为 0）
    assert(std::fabs(Vec3(1,0,0).Dot(Vec3(0,1,0))) < 1e-6f);
    // 3. 点积（同向）
    assert(std::fabs(Vec3(2,0,0).Dot(Vec3(3,0,0)) - 6.0f) < 1e-4f);
    // 4. 叉积 x̂ × ŷ = ẑ
    Vec3 cr = Vec3(1,0,0).Cross(Vec3(0,1,0));
    assert(std::fabs(cr.x) < 1e-6f && std::fabs(cr.y) < 1e-6f && std::fabs(cr.z-1) < 1e-6f);
    // 5. 叉积结果与两边都垂直
    assert(std::fabs(cr.Dot(Vec3(1,0,0))) < 1e-6f);
    // 6. 零向量归一化不产生 NaN
    assert(std::fabs(Vec3(0,0,0).Normalized().LengthSq()) < 1e-6f);
    printf("习题 45.1 全部通过\n");
    return 0;
}
```

> [!tip] 这道题练什么
> ① **点积**衡量方向一致性；② **叉积**得垂直向量（`x̂ × ŷ = ẑ`）；
> ③ **归一化防除零**——零向量归一化返回零向量而不是 `NaN`（本项目 `Normalized` 同款保护）。

### 习题 45.2 判断目标在身前还是身后（★★）

**任务要求**：给定相机前方向 `forward` 和"相机→目标"方向 `toTarget`，
用点积判断目标在前方还是后方（`Dot > 0` 前方，`< 0` 后方）。

**参考实现**：

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

struct V { float x, y, z; };
float Dot(V a, V b) { return a.x*b.x + a.y*b.y + a.z*b.z; }

int main() {
    V forward{1, 0, 0};                  // 相机朝 +X
    V toFront{10, 0, 0};                 // 目标在前方
    V toBack{-10, 0, 0};                 // 目标在后方
    V toSide{0, 10, 0};                  // 目标在侧面（垂直）

    printf("前方 Dot=%+.0f  后方 Dot=%+.0f  侧面 Dot=%+.0f\n",
           Dot(forward, toFront), Dot(forward, toBack), Dot(forward, toSide));
    assert(Dot(forward, toFront) > 0);   // 前方：正
    assert(Dot(forward, toBack)  < 0);   // 后方：负
    assert(std::fabs(Dot(forward, toSide)) < 1e-6f);  // 侧面：0
    printf("习题 45.2 全部通过\n");
    return 0;
}
```

> [!note] 这是 ESP 的第一个筛选条件
> 本项目遍历 Actor 时，先用 `Dot(朝向, 到目标方向) > 0` 快速排除"身后"的对象，
> 再算更贵的投影。**用便宜的点积先筛，能省大量计算**（第 52 章剔除）。
