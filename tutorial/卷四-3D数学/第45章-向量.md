# 第 45 章 · 向量

> [!abstract] 本章目标
> 从"箭头"到代码，掌握向量的四种运算，并理解它们在游戏里的实际含义。
> 本项目 `Vec2/Vec3`（`VectorTools.h`）就是本章的实现对象。

## 先看一个具体问题

你在世界坐标 `(100, 200, 50)`，敌人在 `(400, 600, 50)`。
问：敌人在你的哪个方向？有多远？

```cpp
Vec3 me   = {100, 200, 50};
Vec3 enemy = {400, 600, 50};

Vec3 dir = enemy - me;        // (300, 400, 0)  方向 + 距离
float dist = dir.Length();    // 500             距离
Vec3 norm = dir / dist;       // (0.6, 0.8, 0)   纯方向（单位向量）
```

三个操作：**减法得方向、求模得距离、除法得单位方向**。
整个 ESP 和自瞄系统，反复用的就是这三招。

## 向量是什么

两种理解，都成立：

| 视角 | 含义 | 例子 |
|---|---|---|
| 几何 | 有方向、有长度的箭头 | 从 A 指向 B |
| 代数 | 一组有序的数 | `(3, 4, 0)` |

本项目用后者存储，用前者理解。

```cpp
struct Vec3 {
    float x, y, z;
};
```

## 四种基础运算

### 1. 加减法（平移）

```cpp
Vec3 a = {1, 2, 3}, b = {10, 20, 30};
Vec3 c = a + b;      // (11, 22, 33)
Vec3 d = b - a;      // (9, 18, 27)
```

几何意义：`b - a` 是"从 a 指向 b 的箭头"。

> [!note] 位置 - 位置 = 方向；位置 + 方向 = 位置
> ```cpp
> Vec3 敌人相对我 = 敌人位置 - 我的位置;    // 方向
> Vec3 我前方的点 = 我的位置 + 朝向 * 100;  // 位置
> ```
> 位置 + 位置 没有意义（两个点相加是什么？）

### 2. 数乘（缩放）

```cpp
Vec3 a = {1, 2, 3};
Vec3 b = a * 2.5f;    // (2.5, 5, 7.5)
```

改变长度，方向不变（负数则反向）。

### 3. 点积（Dot Product）★最重要

```cpp
float Dot(const Vec3 a, const Vec3 b) {
    return a.x*b.x + a.y*b.y + a.z*b.z;
}
```

结果是一个**数**，不是向量。

> [!tip] 点积在量什么
> 一句话：**点积衡量"两个方向有多一致"**。
> - 同向 → 点积最大（正数）
> - 垂直 → 点积为 0（"完全不搭边"）
> - 反向 → 点积最小（负数）
>
> 所以自瞄里用 `Dot(朝向, 到目标的方向)` 判断"目标在不在我前方"——
> 点积越大，目标越正对我。

它的几何意义：

```
Dot(a, b) = |a| × |b| × cos(θ)
```

θ 是两向量的夹角。推论：

| 情况 | Dot 值 | 含义 |
|---|---|---|
| 同向 | 正的最大 | 夹角 0° |
| 垂直 | **0** | 夹角 90° |
| 反向 | 负的最大 | 夹角 180° |

**单位化后，Dot 就是 cos(θ)**：

```cpp
float cosAngle = Dot(a.Normalized(), b.Normalized());
float angle = acosf(cosAngle) * 180.0f / PI;    // 角度
```

> [!tip] 本项目里的两处点积用法
> 1. **判断目标在不在视野内**：`Dot(朝向, 到目标的方向) > cos(FOV/2)`
> 2. **判断在身前还是身后**：`Dot > 0` 在身前，`< 0` 在身后

本项目用的是角度比较（第 56 章会说明为什么不用点积），但原理相同。

### 4. 叉积（Cross Product）

```cpp
Vec3 Cross(const Vec3 a, const Vec3 b) {
    return {
        a.y*b.z - a.z*b.y,
        a.z*b.x - a.x*b.z,
        a.x*b.y - a.y*b.x
    };
}
```

结果是**垂直于 a 和 b 的向量**，长度 = |a||b|sin(θ)。

用途：
- 求平面的法线（两个边向量的叉积）
- 判断左右（在 2D 里看 z 分量符号）
- 构建坐标系（已知前向量和上向量，叉积得右向量）

本项目没直接用叉积，但第 47 章构建旋转矩阵时会用到这个概念。

## 长度与归一化

```cpp
float Length(const Vec3 v) {
    return sqrtf(v.x*v.x + v.y*v.y + v.z*v.z);
}

Vec3 Normalized(const Vec3 v) {
    float len = Length(v);
    if (len < 1e-6f) return {0, 0, 0};     // ★ 必须防除零
    return {v.x/len, v.y/len, v.z/len};
}
```

> [!danger] 零向量归一化会除零
> `sqrtf(0) = 0` → 除以 0 → `inf` 或 `nan`。
> 这个 nan 会污染后续所有计算，最终表现为"画出来的线飞了"。
> 本项目里凡是除法都有保护：
> ```cpp
> float w = matrix[3]*obj.X + ...;
> if (w < 0.001f) return false;      // 防除零
> ```

## 距离

```cpp
float Dist(const Vec3 a, const Vec3 b) {
    return Length(b - a);
}

// 性能优化：比较距离时不开方
float DistSq(const Vec3 a, const Vec3 b) {
    Vec3 d = b - a;
    return d.x*d.x + d.y*d.y + d.z*d.z;
}
```

比较远近时，`DistSq` 就够了（平方是单调的），省一次 `sqrtf`。

本项目选目标时用的是**屏幕距离的平方**：

```cpp
const float 目标dx = rootScreen.X - px;
const float 目标距离 = 目标dx*目标dx + 目标dy*目标dy;   // 没开方
```

> `Vec3` 来自 `VectorTools.h`（数学层），
> `Vector3A` 来自 `draw.h`（绘制层，早期代码）。
> 新代码统一用 `Vec3`，老代码保留 `Vector3A`。
> 你自己写时**只用一套**。

## Vec2：屏幕坐标

```cpp
struct Vec2 { float x, y; };
```

用法：
- 屏幕像素坐标（0,0 在左上角，y 向下）
- UV 坐标
- 摇杆输入

注意 **屏幕坐标 y 轴向下**，和数学坐标系相反。第 51 章的 W2S 会处理这个翻转。

## 动手：实现并验证向量库

```cpp
#include <cmath>
#include <cstdio>
#include <cassert>

struct Vec3 {
    float x = 0, y = 0, z = 0;
    Vec3() = default;
    Vec3(float x_, float y_, float z_) : x(x_), y(y_), z(z_) {}

    Vec3 operator+(const Vec3 &v) const { return {x+v.x, y+v.y, z+v.z}; }
    Vec3 operator-(const Vec3 &v) const { return {x-v.x, y-v.y, z-v.z}; }
    Vec3 operator*(float s) const { return {x*s, y*s, z*s}; }
    Vec3 operator/(float s) const { return {x/s, y/s, z/s}; }

    float Dot(const Vec3 &v) const { return x*v.x + y*v.y + z*v.z; }
    Vec3  Cross(const Vec3 &v) const {
        return {y*v.z - z*v.y, z*v.x - x*v.z, x*v.y - y*v.x};
    }
    float LengthSq() const { return x*x + y*y + z*z; }
    float Length() const { return sqrtf(LengthSq()); }
    Vec3  Normalized() const {
        float len = Length();
        return len < 1e-6f ? Vec3{} : (*this) / len;
    }
};

int main(void) {
    // 1. 方向 + 距离（开篇的例子）
    Vec3 me{100, 200, 50}, enemy{400, 600, 50};
    Vec3 dir = enemy - me;
    printf("方向=(%.0f,%.0f,%.0f) 距离=%.0f\n",
           dir.x, dir.y, dir.z, dir.Length());
    assert(fabsf(dir.Length() - 500.0f) < 0.001f);

    // 2. 归一化后长度必为 1
    Vec3 n = dir.Normalized();
    printf("单位方向=(%.2f,%.2f,%.2f) 模=%.6f\n", n.x, n.y, n.z, n.Length());
    assert(fabsf(n.Length() - 1.0f) < 1e-5f);

    // 3. 点积：垂直为 0
    Vec3 a{1,0,0}, b{0,1,0}, c{1,1,0};
    assert(a.Dot(b) == 0.0f);                      // 垂直
    assert(fabsf(a.Dot(a) - 1.0f) < 1e-6f);        // 自己点自己 = 长度平方

    // 4. 夹角
    float cosA = a.Dot(c.Normalized());
    printf("a 与 c 夹角 = %.1f 度\n", acosf(cosA) * 180.0f / 3.14159265f);

    // 5. 叉积：垂直且与两边都垂直
    Vec3 cr = a.Cross(b);
    printf("a×b = (%.0f,%.0f,%.0f)\n", cr.x, cr.y, cr.z);   // (0,0,1)
    assert(fabsf(cr.Dot(a)) < 1e-6f && fabsf(cr.Dot(b)) < 1e-6f);

    // 6. 零向量安全
    Vec3 zero{0,0,0};
    assert(zero.Normalized().LengthSq() == 0.0f);   // 不崩、不产生 nan
    printf("全部通过\n");
    return 0;
}
```

编译：`g++ -std=c++17 -Wall vec.cpp -o vec -lm`

**必须验证的 6 条**：距离 500、单位向量模为 1、垂直点积为 0、
夹角 45 度、叉积与两边垂直、零向量不产生 nan。
