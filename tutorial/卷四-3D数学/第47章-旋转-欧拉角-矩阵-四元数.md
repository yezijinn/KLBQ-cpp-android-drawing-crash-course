# 第 47 章 · 旋转的三种表示

> [!abstract] 本章目标
> 掌握欧拉角、旋转矩阵、四元数三种表示法及其互转，
> 理解本项目为什么从内存读四元数、却用欧拉角做运算。

## 先看本项目的实际数据流

```
内存里读到的骨骼数据：四元数 Quat{x,y,z,w}
        ↓ TransformToMatrix()
    旋转矩阵 Matrix
        ↓ MatrixMulti(骨骼局部, 父级世界)
    世界坐标
        
相机数据：Rotator{Pitch, Yaw, Roll}   ← 欧拉角
        ↓ rotatorToMatrix()
    世界矩阵
```

**存用四元数，算用欧拉角，中间过矩阵。** 三种表示各有分工。

## 一、欧拉角（Euler Angles）

用三个角度表示旋转。本项目：

```cpp
struct Rotator {
    float Pitch;    // 俯仰：抬头低头（绕 Y 轴）
    float Yaw;      // 偏航：左右转（绕 Z 轴）
    float Roll;     // 翻滚：歪头（绕 X 轴）
};
```

| 名称 | 日常说法 | UE4 中的轴 |
|---|---|---|
| Pitch | 抬头/低头 | Y 轴 |
| Yaw | 左右转头 | Z 轴 |
| Roll | 歪头 | X 轴 |

> [!note] UE4 的坐标系
> UE4 用 **Z 向上**的左手坐标系：
> - X 向前
> - Y 向右
> - Z 向上
>
> 这和 OpenGL 的"Y 向上"不同。本项目所有公式都是 UE4 约定，
> 这也是为什么第 49 章的视图矩阵里 forward 分量是 `(cy*cp, sy*cp, sp)`——z 分量是 sin(pitch)。

### 优点与缺点

| 优点 | 缺点 |
|---|---|
| 直观，人能读懂 | **万向节死锁（Gimbal Lock）** |
| 便于插值限幅 | 插值不自然 |
| 存储紧凑（3 个 float） | 组合旋转要转矩阵 |

**万向节死锁**：当 Pitch = ±90°（正上/正下看）时，
Yaw 和 Roll 变成同一个轴，失去一个自由度。

> [!tip] 打个比方
> 想象你手里拿一个**地球仪**，它有三个可以转的环（Pitch/Yaw/Roll）。
> 当你把最内圈转到"南北极对准"时，有两个环的转轴**重合**了——
> 这时你转哪个，效果都一样，等于**丢了一个转法**。这就是死锁。
>
> 后果：此时你没法"只调朝向、不调翻滚"，自瞄就会失控。
> 四元数没有这个问题。

```cpp
Rotator r = {90, 0, 0};     // 抬头 90 度
// 此时改 Yaw 和改 Roll 效果一样 → 丢了一个自由度
```

> [!tip] 本项目为什么不担心
> 游戏里相机的 Pitch 通常被限制在 ±89°，
> 死锁点不会到达。所以欧拉角够用。
> 真要做万向自由旋转（飞行器、VR），必须用四元数。

## 二、旋转矩阵

3×3（或 4×4 的左上角）表示旋转。

绕 Z 轴转 θ：

```
┌              ┐
│ cosθ  -sinθ 0│
│ sinθ   cosθ 0│
│ 0      0    1│
└              ┘
```

本项目的 `rotatorToMatrix`：

```cpp
Matrix rotatorToMatrix(const Rotator rotation) {
    float radPitch = rotation.Pitch * (M_PI / 180.0f);
    float radYaw   = rotation.Yaw   * (M_PI / 180.0f);
    float radRoll  = rotation.Roll  * (M_PI / 180.0f);

    float SP = sinf(radPitch), CP = cosf(radPitch);
    float SY = sinf(radYaw),   CY = cosf(radYaw);
    float SR = sinf(radRoll),  CR = cosf(radRoll);

    Matrix m;
    m.M[0][0] = (CP * CY);
    m.M[0][1] = (CP * SY);
    m.M[0][2] = (SP);
    m.M[0][3] = 0;

    m.M[1][0] = (SR * SP * CY - CR * SY);
    m.M[1][1] = (SR * SP * SY + CR * CY);
    m.M[1][2] = (-SR * CP);
    m.M[1][3] = 0;

    m.M[2][0] = (-(CR * SP * CY + SR * SY));
    m.M[2][1] = (CY * SR - CR * SP * SY);
    m.M[2][2] = (CR * CP);
    m.M[2][3] = 0;

    m.M[3][0] = 0; m.M[3][1] = 0; m.M[3][2] = 0; m.M[3][3] = 1;
    return m;
}
```

这就是 UE4 的 `FRotator::ToMatrix()`：先 Roll，再 Pitch，再 Yaw 的复合。

**关键**：矩阵的三行分别是三个基向量：

```
第 0 行 = 前方向（Forward）
第 1 行 = 右方向（Right）
第 2 行 = 上方向（Up）
```

验证（Pitch=0, Yaw=0, Roll=0）：

```
M[0] = (1, 0, 0)   ← 前方 = +X ✓
M[1] = (0, 1, 0)   ← 右方 = +Y ✓
M[2] = (0, 0, 1)   ← 上方 = +Z ✓
```

本项目取前方向：

```cpp
Vec3 GetForward(const Rotator rotation) {
    float SP = sinf(rotation.Pitch * PI/180);
    float CP = cosf(rotation.Pitch * PI/180);
    float SY = sinf(rotation.Yaw   * PI/180);
    float CY = cosf(rotation.Yaw   * PI/180);
    return {CP * CY, CP * SY, SP};      // 就是矩阵第 0 行
}
```

对照 `rotatorToMatrix` 的 `M[0][0..2] = (CP*CY, CP*SY, SP)`——**完全一致**。

## 三、四元数（Quaternion）

```cpp
struct Quat {
    float x, y, z, w;
};
```

> [!note] 用大白话理解四元数
> 先说结论：**四元数就是"用一种不直观、但计算上很安全的方式来表示旋转"**。
>
> 它用 4 个数 `(x, y, z, w)` 描述"绕某个轴转多少度"，而不是像欧拉角那样分别记录三个角度。
> 为什么需要它？因为欧拉角有两个毛病（万向节死锁、插值不自然），四元数都能避开。
>
> 你**不需要会推导**四元数，只要记住三件事：
> 1. 它长这样：`Quat{x, y, z, w}`（4 个 float）
> 2. 它能表示任意旋转，且不会"死锁"
> 3. 用它转矩阵、做插值有现成公式（下面会给）
>
> （"四元数是复数的扩展"这个说法，只在学过复数的人眼里才有意义，**没学过就跳过**。）

补一句来历（了解即可）：四元数在数学上是复数的扩展，可写成 `w + xi + yj + zk`。
但你**完全不需要**用它来理解或使用——下面直接给"用轴和角度生成四元数"的公式：

表示"绕轴 (x,y,z) 旋转 θ"：

```
x = axis.x * sin(θ/2)
y = axis.y * sin(θ/2)
z = axis.z * sin(θ/2)
w =           cos(θ/2)
```

### 优点

| 优点 | 说明 |
|---|---|
| 无万向节死锁 | 任意旋转都安全 |
| 插值平滑 | `slerp` 球面插值，转速均匀 |
| 紧凑 | 4 个 float，比 9 个的矩阵小 |
| 组合快 | 乘法比矩阵乘法便宜 |

> [!note] `slerp` 是什么
> `slerp` = **Spherical Linear Interpolation**（球面线性插值）：在两个**朝向**之间平滑旋转的插值方法。
> - 普通 `lerp` 对角度做线性插值，转角大时会"抄近路"、速度不均
> - `slerp` 沿球面走最短弧，**转速均匀**，适合"平滑转向"
>
> 本项目自瞄的平滑转向就用它（小角度时可用 lerp 近似，省算力）。

所以**引擎内部（骨骼动画）用四元数**。

### 四元数 → 矩阵

本项目的实现（`variable.h`，**源码摘录，不可单独编译**——`BoneTransform`/`Matrix` 见项目）：

```cpp
inline Matrix TransformToMatrix(const BoneTransform& transform) {
    Matrix matrix = {};

    // 平移放第 4 行（行主序）
    matrix.M[3][0] = transform.Translation.x;
    matrix.M[3][1] = transform.Translation.y;
    matrix.M[3][2] = transform.Translation.z;

    const float x2 = transform.Rotation.x + transform.Rotation.x;
    const float y2 = transform.Rotation.y + transform.Rotation.y;
    const float z2 = transform.Rotation.z + transform.Rotation.z;

    const float xx2 = transform.Rotation.x * x2;
    const float yy2 = transform.Rotation.y * y2;
    const float zz2 = transform.Rotation.z * z2;

    matrix.M[0][0] = (1 - (yy2 + zz2)) * transform.Scale3D.x;
    matrix.M[1][1] = (1 - (xx2 + zz2)) * transform.Scale3D.y;
    matrix.M[2][2] = (1 - (xx2 + yy2)) * transform.Scale3D.z;

    const float yz2 = transform.Rotation.y * z2;
    const float wx2 = transform.Rotation.w * x2;
    matrix.M[2][1] = (yz2 - wx2) * transform.Scale3D.z;
    matrix.M[1][2] = (yz2 + wx2) * transform.Scale3D.y;

    const float xy2 = transform.Rotation.x * y2;
    const float wz2 = transform.Rotation.w * z2;
    matrix.M[1][0] = (xy2 - wz2) * transform.Scale3D.y;
    matrix.M[0][1] = (xy2 + wz2) * transform.Scale3D.x;

    const float xz2 = transform.Rotation.x * z2;
    const float wy2 = transform.Rotation.w * y2;
    matrix.M[2][0] = (xz2 + wy2) * transform.Scale3D.z;
    matrix.M[0][2] = (xz2 - wy2) * transform.Scale3D.x;

    matrix.M[0][3] = 0;
    matrix.M[1][3] = 0;
    matrix.M[2][3] = 0;
    matrix.M[3][3] = 1;
    return matrix;
}
```

这就是标准的四元数转矩阵公式，注意两点：
1. `x2 = x + x` 就是 `2x`（用加法代替乘法，微小优化）
2. 三行分别乘了 `Scale3D` 的对应分量 → 同时应用了缩放

### 单位四元数

```cpp
Quat identity = {0, 0, 0, 1};    // 不旋转
```

`w=1, xyz=0` 表示"旋转 0 度"。

## 欧拉角 ↔ 向量

本项目自瞄里的核心转换（`SilentAim.h`）：

> [!note] `atan2(y, x)` 是什么
> 反三角函数 `atan(x)` 只知道比值，**分不清象限**（45° 和 225° 的 tan 都是 1）。
> `atan2(y, x)` 接收两个参数，能根据 x、y 的正负**自动判断象限**，返回 `(-π, π]` 的完整角度。
> 这里 `atan2(v.z, 水平)` 就是"已知对边 z、邻边水平距离，求俯仰角"。

```cpp
inline Rotator 向量转角度(const Vec3 &v) {
    const float 水平 = std::sqrt(v.x * v.x + v.y * v.y);
    Rotator r{};
    r.Pitch = std::atan2(v.z, 水平) * 180.0f / PI_F;   // 俯仰
    r.Yaw   = std::atan2(v.y, v.x)  * 180.0f / PI_F;   // 偏航
    r.Roll  = 0.0f;
    return r;
}
```

推导：

```
给定方向 v = (x, y, z)
水平投影长度 = sqrt(x² + y²)
Pitch = atan2(z, 水平距离)      ← 抬头多少
Yaw   = atan2(y, x)             ← 朝向哪个方位
```

**`atan2` 而不是 `atan`**：`atan2(dy, dx)` 接受两个参数，
能正确处理四个象限（第 56 章详述）。

## 角度归一化

自瞄里到处可见：

```cpp
inline float 归一角差(float a, float b) {
    float d = a - b;
    while (d >  180.0f) d -= 360.0f;
    while (d < -180.0f) d += 360.0f;
    return d;
}
```

为什么需要？角度是**周期**的：350° 和 -10° 是同一个方向。

```
从 350° 转到 10°：
  朴素计算：10 - 350 = -340°  → 会往回转一大圈
  归一化后：+20°              → 正确的短路径
```

本项目写角度时也做了归一化：

```cpp
if (累积角度.Yaw >  180.0f) 累积角度.Yaw -= 360.0f;
if (累积角度.Yaw < -180.0f) 累积角度.Yaw += 360.0f;
```

## 三种表示怎么选

| 场景 | 用 |
|---|---|
| 存储/网络传输 | 欧拉角（直观）或四元数（紧凑） |
| 引擎内部骨骼 | 四元数（无死锁、可插值） |
| 实际做变换运算 | 矩阵（一次搞定） |
| 给用户看/调参 | 欧拉角 |
| 插值（平滑转向） | 四元数 slerp，或欧拉角线性插值（小角度时） |

本项目自瞄的平滑用的是**欧拉角线性插值**：

```cpp
const float t = 1.0f / Cfg.平滑度;
float sp = dp * t;
累积角度.Pitch += sp;
```

因为相机 Pitch 不接近 ±90°，欧拉角插值足够，且实现简单。

## 动手：三种表示互转并验证

```cpp
#include <cstdio>
#include <cmath>
#include <cassert>

struct Rotator { float Pitch=0, Yaw=0, Roll=0; };
struct Quat { float x=0,y=0,z=0,w=1; };

constexpr float PI = 3.14159265358979323846f;
static float Rad(float d) { return d * PI / 180.0f; }
static float Deg(float r) { return r * 180.0f / PI; }

// 欧拉角 → 前方向（本项目 GetForward）
struct Vec3 { float x=0,y=0,z=0; };
Vec3 GetForward(const Rotator &r) {
    float SP = sinf(Rad(r.Pitch)), CP = cosf(Rad(r.Pitch));
    float SY = sinf(Rad(r.Yaw)),   CY = cosf(Rad(r.Yaw));
    return {CP*CY, CP*SY, SP};
}

// 方向 → 欧拉角（本项目 向量转角度）
Rotator DirToRot(const Vec3 &v) {
    float horiz = sqrtf(v.x*v.x + v.y*v.y);
    return { Deg(atan2f(v.z, horiz)), Deg(atan2f(v.y, v.x)), 0 };
}

// 绕 Z 轴转 θ 的四元数
Quat QuatFromAxisAngle(float ax, float ay, float az, float deg) {
    float half = Rad(deg) * 0.5f;
    float s = sinf(half);
    return {ax*s, ay*s, az*s, cosf(half)};
}

int main(void) {
    // 1. 前方向：Yaw=0 → +X；Yaw=90 → +Y
    Vec3 f0 = GetForward({0, 0, 0});
    printf("Yaw=0   前方向=(%.2f,%.2f,%.2f)\n", f0.x, f0.y, f0.z);   // (1,0,0)
    Vec3 f90 = GetForward({0, 90, 0});
    printf("Yaw=90  前方向=(%.2f,%.2f,%.2f)\n", f90.x, f90.y, f90.z); // (0,1,0)
    assert(fabsf(f0.x - 1.0f) < 1e-5f);
    assert(fabsf(f90.y - 1.0f) < 1e-5f);

    // 2. 往返：方向 → 角度 → 方向
    Vec3 v{3, 4, 5};
    Rotator r = DirToRot(v);
    printf("方向(3,4,5) → Pitch=%.1f Yaw=%.1f\n", r.Pitch, r.Yaw);
    Vec3 back = GetForward(r);
    printf("还原方向=(%.2f,%.2f,%.2f)\n", back.x, back.y, back.z);

    // 3. 四元数：绕 Z 转 90 度
    Quat q = QuatFromAxisAngle(0, 0, 1, 90);
    printf("绕Z转90°: (%.3f,%.3f,%.3f,%.3f)\n", q.x,q.y,q.z,q.w);
    // 期望 (0, 0, 0.7071, 0.7071)
    assert(fabsf(q.z - 0.70710678f) < 1e-5f);
    assert(fabsf(q.w - 0.70710678f) < 1e-5f);

    // 4. 单位四元数 = 不旋转
    Quat id{0,0,0,1};
    (void)id;

    printf("全部通过\n");
    return 0;
}
```

注意第 2 项：`GetForward` 只用了 Pitch 和 Yaw，
所以还原出来的方向是**归一化后**的 (3,4,5)/|v|，数值不同但方向相同。
验证方法：比较归一化后的结果。
