# 第 93 章 · 碰撞体类型

> [!abstract] 本章目标
> 理解物理引擎用哪些形状表示"实体"，以及每种形状在内存里长什么样。
> 这是从物理数据重建可见几何的第一步。

## 先看为什么需要碰撞体

渲染用高精度模型（几万个三角形），但物理计算不能这么干——太慢。

**解法：用简化的碰撞体（Collider）代替真实模型。**

```
渲染模型：50000 个三角形（精细的人形）
碰撞体  ：一个胶囊（ Capsule）+ 几个盒子
```

物理引擎只跟碰撞体打交道。所以：
- 碰撞体是"物体在物理世界里的形状"
- 也从侧面反映了"哪里是实心的"（可用于遮挡判定）

## PhysX 的几何类型

本项目 `PhysX.h` 里的定义：

```cpp
enum class PxGeometryType : int32_t {
    eSPHERE       = 0,     // 球体
    ePLANE        = 1,     // 平面
    eCAPSULE      = 2,     // 胶囊体（圆柱 + 两端半球）
    eBOX          = 3,     // 盒子
    eCONVEXMESH   = 4,     // 凸包网格
    eTRIANGLEMESH = 5,     // 三角形网格（可凹）
    eHEIGHTFIELD  = 6,     // 高度场（地形）
    eGEOMETRY_COUNT,
    eINVALID = -1
};
```

七种，逐个说明。

## 1. 球体（Sphere）

```
    ___
   /   \
  |  ●  |     半径 r
   \___/
```

内存结构：

```cpp
struct PxSphereGeometry {
    PxGeometryType type;      // eSPHERE
    float radius;             // 半径
};
```

**最简单**：一个半径就够。

用途：球、粒子、简单的触发器。

## 2. 盒子（Box）

```
    ┌─────┐
   /     /|
  ┌─────┐ |      半长 hx, hy, hz
  |     | /
  |_____|/
```

```cpp
struct PxBoxGeometry {
    PxGeometryType type;
    PxVec3 halfExtents;       // 半长（不是全长！）
};
```

> [!warning] 是"半长"不是"全长"
> 一个 100×100×100 的箱子，`halfExtents = (50, 50, 50)`。
> 搞错会得到两倍大的盒子。

用途：箱子、墙、建筑构件。**游戏里最常见。**

## 3. 胶囊体（Capsule）

```
   ╭───╮
   │   │      半径 r
   │   │      半高 halfHeight（圆柱部分的一半）
   │   │
   ╰───╯
```

```cpp
struct PxCapsuleGeometry {
    PxGeometryType type;
    float radius;             // 半径
    float halfHeight;         // 圆柱部分的半高
};
```

用途：**角色碰撞体**（人形角色几乎都用胶囊）。

本项目读取角色的胶囊体：

```cpp
const float 胶囊体数值 = dr->Read<float>(
    dr->Read<uint64_t>(objectAddress + 0x380) + 0x54C);
```

## 4. 凸包（Convex Mesh）

"凸"的意思：任意两点连线都在形状内部。

```
  ╱╲         ╱╲╱╲      ← 左边是凸的，右边不是
 ╱  ╲       ╱╲  ╱
╱____╲     ╱__╲╱
```

```cpp
struct PxConvexMeshGeometry {
    PxGeometryType type;
    PxConvexMesh *convexMesh;    // 指向网格数据
    PxVec3        scale;         // 缩放
    // ...
};
```

网格数据里存：顶点数组 + 多边形面（每个面是顶点索引的环）。

用途：不规则但凸的物体（石头、机械零件）。

## 5. 三角形网格（Triangle Mesh）

可以是凹的，用于**静态场景**：

```cpp
struct PxTriangleMeshGeometry {
    PxGeometryType type;
    PxTriangleMesh *triangleMesh;   // 顶点 + 索引
    PxVec3         scale;
    // ...
};
```

数据：

```
顶点数组: [v0, v1, v2, ...]          每个 Vec3
索引数组: [0,1,2, 0,2,3, ...]         每 3 个一组
```

用途：地形、建筑、静态装饰。

## 6. 高度场（HeightField）

地形专用：

```
     /\    /\
    /  \  /  \
___/    \/    \_____
```

```cpp
struct PxHeightFieldGeometry {
    PxGeometryType type;
    PxHeightField *heightField;   // 高度采样数据
    float heightScale;
    float rowScale;
    float columnScale;
};
```

数据是一个二维网格，每格存一个高度值：

```
heights[row][col] = 高度
```

用途：**地形**。游戏地图的地面基本都是它。

## 7. 平面（Plane）

无限大的平面，通常用作物理世界的地面边界。实际游戏里很少作为可见物体。

## 对照表

| 类型 | 数据量 | 能否凹陷 | 典型用途 | 重建难度 |
|---|---|---|---|---|
| Sphere | 极小 | — | 球、粒子 | 简单 |
| Box | 小 | — | 箱子、墙 | **简单** |
| Capsule | 小 | — | 角色 | 中等 |
| ConvexMesh | 中 | 否 | 不规则物体 | 中等 |
| TriangleMesh | 大 | **是** | 静态场景 | **简单**（直接用） |
| HeightField | 中 | 是 | 地形 | 中等 |

## 本项目的处理

第 98 章会讲如何从每种类型生成三角形。先剧透结论：

| 类型 | 本项目处理 |
|---|---|
| Box | ✓ 生成 8 顶点 12 三角形 |
| TriangleMesh | ✓ 直接用索引 |
| ConvexMesh | ✓ 扇形三角化 |
| HeightField | ✓ 网格化 |
| Sphere | ✗ 只读半径，不生成几何 |
| Capsule | ✗ 只读半径，不生成几何 |

## 数据结构：Shape 与 Actor

PhysX 的组织方式：

```
PxScene（场景）
  └─ PxRigidActor（刚体）
       ├─ PxShape（形状 1）
       │    └─ PxGeometry（几何数据）
       ├─ PxShape（形状 2）
       └─ ...
```

- **Actor**：一个物体（可能由多个形状组成）
- **Shape**：形状 + 材质 + 本地变换
- **Geometry**：纯粹的几何数据

本项目遍历：

```cpp
// 场景 → 刚体数组
uint64_t scene = dr->Read<uint64_t>(physxPtr + 0x8);
uint64_t actors = dr->Read<uint64_t>(scene + 0x25E8);
```

## 动态 vs 静态

| | 动态（Dynamic） | 静态（Static） |
|---|---|---|
| 会移动吗 | 会 | 不会 |
| 例子 | 角色、箱子、门 | 地形、建筑 |
| 更新频率 | 高（每帧） | 低（加载时） |
| BVH 重建 | 需要频繁 | 一次就够 |

本项目分了三类场景（第 99 章）：

```
DynamicLoadScene     静态场景（2s 更新）
HeightFieldScene     高度场（3s 更新）
DynamicRigidScene    动态刚体（300ms 更新）
```

## 动手：观察你的 demo 引擎

给 demo 引擎加上几种碰撞体：

```cpp
enum ColliderType { COL_BOX, COL_SPHERE, COL_CAPSULE };

struct Collider {
    ColliderType type;
    union {
        struct { float hx, hy, hz; } box;       // 半长
        struct { float r; } sphere;
        struct { float r, halfH; } capsule;
    };
};
```

生成几个物体（2 个盒子、1 个球、1 个胶囊），
然后用外部程序读出来，打印每种的参数。

**验证**：和 demo 自己打印的值对比，必须一致。特别检查盒子的"半长"有没有搞成"全长"。
