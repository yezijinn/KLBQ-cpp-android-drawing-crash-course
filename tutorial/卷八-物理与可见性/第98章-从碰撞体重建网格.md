# 第 98 章 · 从碰撞体重建网格

> [!abstract] 本章目标
> 把第 93 章的碰撞体变成第 94 章的三角形网格。
> 这是本项目 `PhysX.h` 最核心的部分。

> [!note] 承上
> 第 93-94 章认识了碰撞体和网格，第 97 章学会了 Embree。
> 本章把它们串起来：**从内存里的碰撞体重建出三角形，提交给 Embree**。这是 `PhysX.h` 最核心的部分。

## 先看整体流程

```
PhysX 场景
  ↓ 遍历刚体
每个 Actor
  ↓ 遍历 Shape
每个 Shape
  ↓ 读几何类型和数据
生成三角形
  ↓ 应用 Actor 的变换
世界空间的三角形
  ↓ 提交给 Embree
可查询的 BVH
```

## 关键：变换

碰撞体数据是**局部坐标**，要乘上 Actor 的世界变换：

```cpp
// 局部顶点 → 世界顶点
Vec3 world = TransformPoint(localVertex, actorTransform);
```

`PxTransform` 结构：

```cpp
struct PxTransform {
    PxQuat q;        // 旋转（四元数）
    PxVec3 p;        // 位置
};
```

变换公式（第 47 章讲过）：

```
world = rotate(q, local) + p
```

四元数旋转向量：

```cpp
Vec3 RotateByQuat(const Vec3 &v, const Quat &q) {
    // v' = v + 2 * cross(q.xyz, cross(q.xyz, v) + q.w * v)
    Vec3 t = Cross(q.xyz, v) * 2.0f;
    return v + t * q.w + Cross(q.xyz, t);
}
```

## 逐类型重建

### Box → 12 个三角形

```cpp
void BuildBox(float hx, float hy, float hz,
              const PxTransform &transform,
              std::vector<Vec3> &outVerts,
              std::vector<uint32_t> &outIdx) {
    uint32_t base = outVerts.size();

    // 8 个局部顶点
    Vec3 local[8] = {
        {-hx,-hy,-hz}, { hx,-hy,-hz}, { hx, hy,-hz}, {-hx, hy,-hz},
        {-hx,-hy, hz}, { hx,-hy, hz}, { hx, hy, hz}, {-hx, hy, hz},
    };

    // 变换到世界并加入
    for (auto &v : local) {
        Vec3 r = RotateByQuat(v, transform.q);
        outVerts.push_back(r + transform.p);
    }

    // 12 个三角形
    static const uint32_t idx[] = {
        0,2,1, 0,3,2,      // 底
        4,5,6, 4,6,7,      // 顶
        0,1,5, 0,5,4,      // 前
        3,7,6, 3,6,2,      // 后
        0,4,7, 0,7,3,      // 左
        1,2,6, 1,6,5,      // 右
    };
    for (int i = 0; i < 36; i++)
        outIdx.push_back(base + idx[i]);
}
```

### TriangleMesh → 直接用

```cpp
void BuildTriangleMesh(const PxTriangleMesh &mesh,
                       const PxTransform &transform,
                       std::vector<Vec3> &outVerts,
                       std::vector<uint32_t> &outIdx) {
    uint32_t base = outVerts.size();

    // 顶点（16 位或 32 位索引决定数量上限）
    for (uint32_t i = 0; i < mesh.vertexCount; i++) {
        Vec3 local = mesh.vertices[i];
        Vec3 r = RotateByQuat(local, transform.q);
        outVerts.push_back(r + transform.p);
    }

    // 索引
    for (uint32_t i = 0; i < mesh.indexCount; i++)
        outIdx.push_back(base + mesh.indices[i]);
}
```

### ConvexMesh → 扇形三角化

```cpp
void BuildConvexMesh(const PxConvexMesh &mesh,
                     const PxTransform &transform,
                     std::vector<Vec3> &outVerts,
                     std::vector<uint32_t> &outIdx) {
    uint32_t base = outVerts.size();

    for (uint32_t i = 0; i < mesh.vertexCount; i++) {
        Vec3 r = RotateByQuat(mesh.vertices[i], transform.q);
        outVerts.push_back(r + transform.p);
    }

    // 每个多边形面扇形三角化
    for (uint32_t f = 0; f < mesh.polygonCount; f++) {
        const auto &poly = mesh.polygons[f];   // {顶点起始, 顶点数}
        for (uint32_t k = 1; k + 1 < poly.count; k++) {
            outIdx.push_back(base + mesh.indices[poly.start + 0]);
            outIdx.push_back(base + mesh.indices[poly.start + k]);
            outIdx.push_back(base + mesh.indices[poly.start + k + 1]);
        }
    }
}
```

### HeightField → 网格化

```cpp
void BuildHeightField(const PxHeightField &hf,
                      float rowScale, float colScale, float heightScale,
                      const PxTransform &transform,
                      std::vector<Vec3> &outVerts,
                      std::vector<uint32_t> &outIdx) {
    uint32_t base = outVerts.size();

    // 采样点 → 顶点
    for (uint32_t r = 0; r < hf.rowCount; r++) {
        for (uint32_t c = 0; c < hf.columnCount; c++) {
            float h = hf.heights[r * hf.columnCount + c] * heightScale;
            Vec3 local = { r * rowScale, c * colScale, h };
            Vec3 world = RotateByQuat(local, transform.q) + transform.p;
            outVerts.push_back(world);
        }
    }

    // 每格两个三角形
    for (uint32_t r = 0; r + 1 < hf.rowCount; r++) {
        for (uint32_t c = 0; c + 1 < hf.columnCount; c++) {
            uint32_t a = base + r * hf.columnCount + c;
            uint32_t b = a + 1;
            uint32_t d = a + hf.columnCount;
            uint32_t e = d + 1;
            outIdx.push_back(a); outIdx.push_back(d); outIdx.push_back(b);
            outIdx.push_back(b); outIdx.push_back(d); outIdx.push_back(e);
        }
    }
}
```

### Sphere / Capsule

本项目**没有生成几何**（只读半径后丢弃）。

要生成的话：

```cpp
// 球：经纬分割
void BuildSphere(float r, int seg, const PxTransform &t, ...) {
    // 同第 94 章的 MakeSphere，再应用变换
}

// 胶囊：圆柱 + 两个半球
void BuildCapsule(float r, float halfH, int seg, ...) {
    // 上半球 + 圆柱侧面 + 下半球
}
```

> [!note] 为什么本项目跳过它们
> - 角色不是用来挡视线的（角色会动，不适合做遮挡判定）
> - 球体/胶囊在场景里通常不是"墙"
> - 生成它们的三角形开销不小（几百个）
>
> 这是个**权衡**：取舍后只保留"能挡住视线的静态几何"。

## 分派：按类型处理

```cpp
bool BuildShape(const PxShape &shape,
                const PxTransform &actorTransform,
                std::vector<Vec3> &outVerts,
                std::vector<uint32_t> &outIdx) {
    // Shape 有自己的本地变换
    PxTransform combined = Combine(actorTransform, shape.localPose);

    switch (shape.geometry.getType()) {
    case PxGeometryType::eBOX:
        BuildBox(static_cast<const PxBoxGeometry&>(shape.geometry).halfExtents,
                 combined, outVerts, outIdx);
        return true;

    case PxGeometryType::eTRIANGLEMESH:
        BuildTriangleMesh(..., combined, outVerts, outIdx);
        return true;

    case PxGeometryType::eCONVEXMESH:
        BuildConvexMesh(..., combined, outVerts, outIdx);
        return true;

    case PxGeometryType::eHEIGHTFIELD:
        BuildHeightField(..., combined, outVerts, outIdx);
        return true;

    case PxGeometryType::eSPHERE:
    case PxGeometryType::eCAPSULE:
    default:
        return false;      // 不生成
    }
}
```

**注意 `shape.localPose`**：Shape 相对 Actor 还有一次变换，要组合起来。

```
世界 = Actor变换 × Shape本地变换
```

## 提交给 Embree

```cpp
void CommitMesh(RTCDevice device, RTCScene scene,
                const std::vector<Vec3> &verts,
                const std::vector<uint32_t> &idx) {
    if (verts.empty() || idx.empty()) return;

    RTCGeometry geom = rtcNewGeometry(device, RTC_GEOMETRY_TYPE_TRIANGLE);

    float *v = (float*)rtcSetNewGeometryBuffer(geom, RTC_BUFFER_TYPE_VERTEX, 0,
                                               RTC_FORMAT_FLOAT3,
                                               sizeof(float)*3, verts.size());
    for (size_t i = 0; i < verts.size(); i++) {
        v[i*3+0] = verts[i].x;
        v[i*3+1] = verts[i].y;
        v[i*3+2] = verts[i].z;
    }

    unsigned *t = (unsigned*)rtcSetNewGeometryBuffer(geom, RTC_BUFFER_TYPE_INDEX, 0,
                                                     RTC_FORMAT_UINT3,
                                                     sizeof(unsigned)*3, idx.size()/3);
    memcpy(t, idx.data(), idx.size() * sizeof(uint32_t));

    rtcCommitGeometry(geom);
    rtcAttachGeometry(scene, geom);
    rtcReleaseGeometry(geom);
}
```

## 本项目的组织：三个场景

```cpp
DynamicLoadScene     静态场景（建筑、地形装饰）   2s 更新
HeightFieldScene     高度场（地形）               3s 更新
DynamicRigidScene    动态刚体（箱子、门）         300ms 更新
```

为什么要分三个？

| 原因 | 说明 |
|---|---|
| 更新频率不同 | 静态的不用频繁重建 |
| 查询可以选择性跳过 | 遮挡只需查静态+高度场 |
| 构建开销分散 | 不同时重建，避免卡顿 |

本项目遮挡判定只查前两个：

```cpp
if (DynamicLoadScene->Raycast(...).hit.geomID != RTC_INVALID_GEOMETRY_ID) return true;
if (HeightFieldScene->Raycast(...).hit.geomID != RTC_INVALID_GEOMETRY_ID) return true;
```

**动态物体（可移动的箱子）不参与遮挡**——合理，因为它们会移动。

## 数据量估算

| 场景 | 物体数 | 三角形数 | Embree 构建 |
|---|---|---|---|
| 静态场景 | 2000 | 50 万 | 1~3 秒 |
| 高度场 | 1 | 8 千 | 10 ms |
| 动态刚体 | 100 | 1 万 | 20 ms |

**50 万三角形的静态场景构建要几秒**——所以：
- 后台线程构建（不阻塞渲染）
- 构建期间用旧场景
- 分块构建（按距离）

## 常见错误

| 错误 | 症状 | 解法 |
|---|---|---|
| 忘了 Actor 变换 | 所有物体堆在原点 | 应用 transform |
| 忘了 Shape 本地变换 | 位置略偏 | 组合两级变换 |
| 半长当全长 | 盒子大一倍 | 检查字段语义 |
| 索引没加 base 偏移 | 三角形全连到第一个物体 | `base + idx[i]` |
| 缠绕顺序不一致 | 背面剔除表现异常 | 保持一致 |
| 凸包非凸 | 三角化错误 | 凸包保证凸，检查数据 |

## 动手：给 demo 引擎加碰撞体并重建

1. 给 demo 引擎加几个碰撞体（盒子、高度场）
2. 外部程序读出来
3. 重建三角形网格
4. 提交给 Embree
5. 做遮挡判定：
   - 相机在盒子左边，目标在右边 → 应该被挡
   - 目标在盒子前面 → 不应该被挡

**这是卷八的核心闭环**：物理数据 → 几何 → BVH → 遮挡判定。
