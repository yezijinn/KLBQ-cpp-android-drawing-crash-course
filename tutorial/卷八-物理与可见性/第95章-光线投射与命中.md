# 第 95 章 · 光线投射与命中

> [!abstract] 本章目标
> 从零实现 ray-triangle 求交，理解命中信息的含义。
> 这是"这个目标被墙挡住了吗"的答案。

## 先看要解决的问题

```
相机 ●━━━━━━━━━━━╳━━━━━━━ 目标
               墙
```

从相机向目标发一条射线，如果先撞到墙 → 目标被遮挡。

## 射线的定义

```cpp
struct Ray {
    Vec3 origin;        // 起点
    Vec3 direction;     // 方向（通常归一化）
    float tMin, tMax;   // 有效距离范围
};
```

射线上任意点：

```
P(t) = origin + direction * t
```

`t` 就是"沿射线走了多远"。

```
t=0     t=1     t=2     t=3
●───────●───────●───────●
起点
```

## 命中信息

```cpp
struct Hit {
    bool  hit;          // 是否命中
    float t;            // 命中距离（t 值）
    Vec3  point;        // 命中点坐标 = origin + dir * t
    Vec3  normal;       // 命中面的法线
    int   geomID;       // 命中的是哪个几何体
};
```

**最重要的两个**：
- `t`：用来判断"谁更近"
- `geomID`：用来知道撞到了什么

## 射线 vs 三角形：Möller–Trumbore 算法

最常用的方法，直接给出重心坐标。

### 原理

三角形内任意点可以表示成重心坐标：

```
P = (1-u-v)·v0 + u·v1 + v·v2
```

其中 `u ≥ 0, v ≥ 0, u+v ≤ 1`。

射线方程：`P = O + t·D`

联立：

```
O + t·D = (1-u-v)·v0 + u·v1 + v·v2
```

整理成三个未知数（t, u, v）的线性方程组，用克莱姆法则解。

### 实现

```cpp
bool RayTriangleIntersect(const Vec3 &orig, const Vec3 &dir,
                          const Vec3 &v0, const Vec3 &v1, const Vec3 &v2,
                          float &outT, float &outU, float &outV) {
    const float EPSILON = 1e-6f;

    Vec3 edge1 = v1 - v0;
    Vec3 edge2 = v2 - v0;

    // 计算行列式（用叉积）
    Vec3 pvec = Cross(dir, edge2);
    float det = Dot(edge1, pvec);

    // 射线与三角形平行？
    if (fabsf(det) < EPSILON) return false;

    float invDet = 1.0f / det;

    // 计算 u 参数并测试
    Vec3 tvec = orig - v0;
    float u = Dot(tvec, pvec) * invDet;
    if (u < 0.0f || u > 1.0f) return false;

    // 计算 v 参数并测试
    Vec3 qvec = Cross(tvec, edge1);
    float v = Dot(dir, qvec) * invDet;
    if (v < 0.0f || u + v > 1.0f) return false;

    // 计算 t
    float t = Dot(edge2, qvec) * invDet;
    if (t < EPSILON) return false;      // 在射线背后

    outT = t; outU = u; outV = v;
    return true;
}
```

### 逐步解释

| 步骤 | 含义 |
|---|---|
| `det = dot(edge1, cross(dir, edge2))` | 行列式，接近 0 表示射线平行于三角形平面 |
| `u` | 重心坐标之一，必须在 [0,1] |
| `v` | 重心坐标之二，必须 `v≥0` 且 `u+v≤1` |
| `t` | 沿射线的距离，必须 > 0（正前方） |

## 射线 vs 包围盒（AABB）

先做便宜的包围盒测试，快速排除大部分三角形：

```cpp
bool RayAABB(const Vec3 &orig, const Vec3 &dir,
             const Vec3 &bmin, const Vec3 &bmax, float &tHit) {
    float tmin = 0.0f, tmax = 1e30f;

    for (int axis = 0; axis < 3; axis++) {
        float o = (axis==0) ? orig.x : (axis==1) ? orig.y : orig.z;
        float d = (axis==0) ? dir.x  : (axis==1) ? dir.y  : dir.z;
        float lo = (axis==0) ? bmin.x : (axis==1) ? bmin.y : bmin.z;
        float hi = (axis==0) ? bmax.x : (axis==1) ? bmax.y : bmax.z;

        if (fabsf(d) < 1e-8f) {
            // 射线平行于这对面
            if (o < lo || o > hi) return false;
        } else {
            float t1 = (lo - o) / d;
            float t2 = (hi - o) / d;
            if (t1 > t2) std::swap(t1, t2);
            tmin = std::max(tmin, t1);
            tmax = std::min(tmax, t2);
            if (tmin > tmax) return false;
        }
    }
    tHit = tmin;
    return true;
}
```

这叫 **slab method**（平板法）：把包围盒看成三组平行的"平板"，
分别求射线进入/离开每组的 t，取交集。

## 暴力遍历：先跑通再说

```cpp
Hit RaycastScene(const std::vector<TriangleMeshData> &meshes,
                 const Vec3 &orig, const Vec3 &dir, float maxDist) {
    Hit best;
    best.hit = false;
    best.t = maxDist;

    for (size_t m = 0; m < meshes.size(); m++) {
        const auto &mesh = meshes[m];
        for (size_t i = 0; i + 2 < mesh.Indices.size(); i += 3) {
            const auto &v0 = mesh.Vertices[mesh.Indices[i]];
            const auto &v1 = mesh.Vertices[mesh.Indices[i+1]];
            const auto &v2 = mesh.Vertices[mesh.Indices[i+2]];

            float t, u, v;
            if (RayTriangleIntersect(orig, dir,
                                     Vec3(v0.x,v0.y,v0.z),
                                     Vec3(v1.x,v1.y,v1.z),
                                     Vec3(v2.x,v2.y,v2.z), t, u, v)) {
                if (t < best.t) {        // ★ 保留最近的
                    best.t = t;
                    best.hit = true;
                    best.geomID = (int)m;
                    best.point = orig + dir * t;
                }
            }
        }
    }
    return best;
}
```

**保留最近的命中**——这才是"遮挡"的正确语义：
只要有任何东西比你更近，你就是被挡住的。

## 遮挡判定的正确用法

```cpp
bool IsOccluded(const Vec3 &from, const Vec3 &to,
                const std::vector<TriangleMeshData> &meshes) {
    Vec3 dir = to - from;
    float dist = dir.Length();
    if (dist < 1e-3f) return false;
    dir = dir / dist;                  // 归一化

    Hit h = RaycastScene(meshes, from, dir, dist);

    // 命中且距离小于目标距离 → 被挡住
    return h.hit && h.t < dist - 1.0f;   // 留 1 单位余量
}
```

**关键**：`tMax` 设为"到目标的距离"。
如果射线在到达目标前就命中了别的东西 → 遮挡。

本项目：

```cpp
static bool 射线被遮挡(const Vector3A &from, const Vector3A &to) {
    if (DynamicLoadScene == nullptr || HeightFieldScene == nullptr) return false;
    physx::PxVec3 origin(from.X, from.Y, from.Z);
    physx::PxVec3 target(to.X, to.Y, to.Z);
    if (DynamicLoadScene->Raycast(origin, target).hit.geomID != RTC_INVALID_GEOMETRY_ID)
        return true;
    if (HeightFieldScene->Raycast(origin, target).hit.geomID != RTC_INVALID_GEOMETRY_ID)
        return true;
    return false;
}
```

注意：**检查两个场景**（静态 + 高度场），任一命中就是遮挡。

## 性能：为什么暴力不行

```
一个中等场景: 10 万个三角形
一次射线:     10 万次求交 × 100ns = 10 ms
一帧 50 个目标: 500 ms          ← 完全不可行
```

**必须有加速结构**——下一章的 BVH。

## 性能优化的三个层次

| 层次 | 手段 | 加速比 |
|---|---|---|
| 1 | 包围盒预筛 | 2~5× |
| 2 | BVH / KD-tree | 100~1000× |
| 3 | 降频（不必每帧都查） | 视情况 |

本项目三层都用了：
- Embree 内部有 BVH（层次 2）
- 只在必要时查（`physx已初始化 && 开了方框或射线`，层次 3）

## 常见错误

| 错误 | 症状 | 修正 |
|---|---|---|
| 方向没归一化 | `t` 不是真实距离 | 归一化 |
| 忘记 `t < best.t` | 得到的不是最近命中 | 取最小 |
| `tMax` 设为无穷 | 目标背后的墙也算遮挡 | 设为到目标的距离 |
| 没处理平行情况 | 除零 → NaN | 判 `fabs(det) < EPS` |
| 只查一个场景 | 地形挡不住 | 所有场景都查 |

## 动手：手写光线投射器

```cpp
int main(void) {
    std::vector<TriangleMeshData> scene;

    // 场景：一个盒子当"墙"
    TriangleMeshData wall;
    MakeBox(20, 200, 100, wall.Vertices, wall.Indices);
    // 平移到 x=100
    for (auto &v : wall.Vertices) v.x += 100;
    scene.push_back(wall);

    // 从原点射向 (200, 0, 0) —— 应该被墙挡住
    Vec3 from = {0, 0, 0};
    Vec3 to   = {200, 0, 0};

    printf("被遮挡? %s\n", IsOccluded(from, to, scene) ? "是" : "否");

    // 射向 (50, 0, 0) —— 墙在 100，还没到
    to = {50, 0, 0};
    printf("被遮挡? %s\n", IsOccluded(from, to, scene) ? "是" : "否");

    // 从侧面绕过去 (100, 300, 0)
    to = {100, 300, 0};
    printf("被遮挡? %s\n", IsOccluded(from, to, scene) ? "是" : "否");

    return 0;
}
```

预期输出：是 / 否 / 否。
