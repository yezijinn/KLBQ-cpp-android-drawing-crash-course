# 第 75 章 · 封装跨进程读写类

> [!abstract] 本章目标
> 把裸系统调用封装成一个好用的类：模板读、字符串读、错误处理、PID 管理。
> 这是 `SysHal` 和 `IDriver` 的设计蓝图。

> [!note] 承上
> 上一章写的是裸系统调用，用起来啰嗦。
> 本章把它**封装成类**（模板读、字符串读、错误处理）——`SysHal` 的设计蓝图。

## 先看想要什么样的 API

调用方希望这么写：

```cpp
MemReader mem(pid);

auto hp     = mem.Read<int32_t>(addr);
auto pos    = mem.Read<Vec3>(addr + 4);
auto name   = mem.ReadString(addr + 16, 64);
auto matrix = mem.Read<Matrix>(matrixAddr);

mem.Write<int32_t>(addr, 9999);
```

而不是每次都构造 `iovec`。**封装的价值就在这里。**

## 类设计

```cpp
class MemReader {
public:
    MemReader() = default;
    explicit MemReader(pid_t pid) : pid_(pid) {}

    // 进程管理
    bool Attach(pid_t pid);
    pid_t Pid() const { return pid_; }
    bool IsValid() const;

    // 原始读写
    int  Read (uint64_t addr, void *buf, size_t size) const;
    int  Write(uint64_t addr, const void *buf, size_t size) const;

    // 模板便捷接口
    template <typename T> T Read (uint64_t addr) const;
    template <typename T> bool Write(uint64_t addr, const T &value) const;

    // 字符串
    std::string ReadString(uint64_t addr, size_t maxLen = 128) const;
    std::string ReadWString(uint64_t addr, size_t maxLen = 128) const;

private:
    pid_t pid_ = 0;
};
```

## 实现

```cpp
#include <sys/uio.h>
#include <cerrno>
#include <cstring>
#include <string>
#include <vector>

class MemReader {
public:
    MemReader() = default;
    explicit MemReader(pid_t pid) : pid_(pid) {}

    bool Attach(pid_t pid) {
        if (pid <= 0) return false;
        pid_ = pid;
        return true;
    }
    pid_t Pid() const { return pid_; }
    bool IsValid() const { return pid_ > 0; }

    int Read(uint64_t addr, void *buf, size_t size) const {
        if (!buf || size == 0 || pid_ <= 0) return -1;

        struct iovec local  = {buf, size};
        struct iovec remote = {(void*)addr, size};

        size_t total = 0;
        while (total < size) {
            ssize_t n = process_vm_readv(pid_, &local, 1, &remote, 1, 0);
            if (n <= 0) break;
            total += (size_t)n;
            local.iov_base  = (char*)buf + total;
            local.iov_len   = size - total;
            remote.iov_base = (char*)addr + total;
            remote.iov_len  = size - total;
        }
        return total > 0 ? (int)total : -1;
    }

    int Write(uint64_t addr, const void *buf, size_t size) const {
        if (!buf || size == 0 || pid_ <= 0) return -1;

        struct iovec local  = {(void*)buf, size};
        struct iovec remote = {(void*)addr, size};

        size_t total = 0;
        while (total < size) {
            ssize_t n = process_vm_writev(pid_, &local, 1, &remote, 1, 0);
            if (n <= 0) break;
            total += (size_t)n;
            local.iov_base  = (char*)buf + total;
            local.iov_len   = size - total;
            remote.iov_base = (char*)addr + total;
            remote.iov_len  = size - total;
        }
        return total > 0 ? (int)total : -1;
    }

    template <typename T>
    T Read(uint64_t addr) const {
        T value = {};
        if (Read(addr, &value, sizeof(T)) <= 0) value = T{};
        return value;
    }

    template <typename T>
    bool Write(uint64_t addr, const T &value) const {
        return Write(addr, &value, sizeof(T)) == (int)sizeof(T);
    }

    std::string ReadString(uint64_t addr, size_t maxLen = 128) const {
        if (addr == 0 || maxLen == 0) return {};
        std::vector<char> buf(maxLen + 1, 0);
        if (Read(addr, buf.data(), maxLen) <= 0) return {};
        buf[maxLen] = '\0';                     // 保证终止
        return std::string(buf.data());          // 遇 \0 自动截断
    }

private:
    pid_t pid_ = 0;
};
```

## 设计要点逐个说

### 1. 失败时返回默认值

```cpp
template <typename T>
T Read(uint64_t addr) const {
    T value = {};
    if (Read(addr, &value, sizeof(T)) <= 0) value = T{};    // ★
    return value;
}
```

读失败返回零值，而不是让调用方拿到半初始化的垃圾。

**但这也带来问题**：调用方分不清"读到 0"和"读失败"。
本项目靠**调用方自己判合理性**解决（第 89 章）：

```cpp
uint64_t obj = mem.Read<uint64_t>(addr);
if (obj == 0) continue;         // 0 一定无效（没有对象在地址 0）
```

### 2. 循环处理部分成功

`process_vm_readv` 可能只读一部分（跨页、权限不均）。
循环推进 `iov_base` 直到读完或失败。

### 3. 字符串必须限长

```cpp
std::string ReadString(uint64_t addr, size_t maxLen = 128) const;
```

**为什么不能无限读**：目标内存里可能没有 `\0`（比如刚好是二进制数据），
一直读下去会碰到一个不可访问的页才停 —— 甚至可能读到几百 KB。

而且 `buf[maxLen] = '\0'` 保证本地缓冲区一定终止。

### 4. 地址用 uint64_t

不用 `int`（32 位会截断）、不用 `long`（Windows/Linux 长度不同）。

### 5. 窄字符 vs 宽字符

UTF-16 字符串要单独处理：

```cpp
std::string ReadWString(uint64_t addr, size_t maxLen = 128) const {
    if (addr == 0) return {};
    std::vector<char16_t> buf(maxLen + 1, 0);
    if (Read(addr, buf.data(), maxLen * 2) <= 0) return {};
    buf[maxLen] = 0;

    std::string out;
    for (size_t i = 0; i < maxLen && buf[i]; i++) {
        char16_t c = buf[i];
        if (c < 0x80) {
            out += (char)c;
        } else if (c < 0x800) {
            out += (char)(0xC0 | (c >> 6));
            out += (char)(0x80 | (c & 0x3F));
        } else {
            out += (char)(0xE0 | (c >> 12));
            out += (char)(0x80 | ((c >> 6) & 0x3F));
            out += (char)(0x80 | (c & 0x3F));
        }
    }
    return out;
}
```

这就是本项目 `GetNameById` 里 `AppendUtf8` 做的事（第 06 章讲过原理）。

## 加上错误诊断

```cpp
const char* LastError() const {
    switch (lastErrno_) {
    case EPERM:  return "权限不足";
    case ESRCH:  return "进程不存在";
    case EFAULT: return "地址不可访问";

    }
}
```

## 加一个"检查进程存活"

```cpp
bool IsProcessAlive() const {
    if (pid_ <= 0) return false;
    // 方法 1：kill(pid, 0) 只检查存在性，不发信号
    return ::kill(pid_, 0) == 0;
    // 方法 2：检查 /proc/pid 是否存在
    // char path[64]; snprintf(path, ..., "/proc/%d", pid_);
    // return access(path, F_OK) == 0;
}
```

**每帧检查一次**，进程没了就停止一切操作——避免无意义的失败调用。

本项目的 `IDriver` 接口（第 80 章）：

```cpp
class IDriver {
public:
    virtual int  Read(uint64_t address, void *buffer, size_t size) = 0;
    virtual int  Write(uint64_t address, void *buffer, size_t size) = 0;
    virtual int  GetPid(std::string_view packageName) = 0;
    virtual int  GetGlobalPid() = 0;
    virtual void SetGlobalPid(int pid) = 0;
    virtual bool GetModuleAddress(std::string_view moduleName, short segmentIndex,
                                  uint64_t *outAddress, bool isStart) = 0;

    template <typename T> T Read(uint64_t address) { ... }
    template <typename T> int Write(uint64_t address, const T &value) { ... }

```

**模板便捷方法定义在基类里，非虚**——所有后端共享同一套实现。

参考：

```cpp
// 指针链
uint64_t FollowChain(uint64_t base, const std::vector<uint64_t> &offsets) const {
    uint64_t cur = base;
    for (size_t i = 0; i < offsets.size(); i++) {
        if (cur == 0) return 0;
        cur = Read<uint64_t>(cur + offsets[i]);
        if (cur == 0) return 0;      // 链断了
    }
    return cur;
}
```
