# 第 79 章 · 共享内存请求-响应模型

> [!abstract] 本章目标
> 手写一个完整的"请求-响应"通信层：分块传输、标志同步、错误处理。
> 这是 `Driver::HandleVirtualMemoryRWEvent` 的完整拆解。

## 先看本项目的实际代码

```cpp
inline void IoCommitAndWait() {
    req->kernel = true;                    // 通知内核：有请求

    while (!req->user) {                   // 等内核处理完
        asm volatile("yield");
    }
    req->user = false;                     // 消费完成标志
}
```

九行，就是一个完整的同步 RPC。

## 请求结构设计

```cpp
struct virtual_memoryrw {
    uint64_t rw_addr;              // 目标地址
    uint8_t  user_buffer[0x1000];  // 数据缓冲（一页）
    int      size;                 // 本次长度
};

struct request_obj {
    volatile bool kernel;          // 用户态→内核：有新请求
    volatile bool user;            // 内核态→用户：处理完成
    volatile request_op op;        // 操作类型
    volatile int status;           // 返回状态

    int tgid;                      // 目标进程

    struct virtual_memoryrw vmemrw_info;
    /* 其它：触摸、陀螺仪、断点... */
};
```

**要点**：
- 四个 `volatile` 控制字段
- 数据区固定 4096 字节（一次最多传一页）
- `tgid` 指定目标进程

## 固定地址映射

```cpp
req = (request_obj *)mmap((void *)0x2025827000, sizeof(request_obj),
                          PROT_READ | PROT_WRITE,
                          MAP_SHARED | MAP_ANONYMOUS | MAP_FIXED_NOREPLACE,
                          -1, 0);
```

| 参数 | 作用 |
|---|---|
| `0x2025827000` | 与内核**约定**的固定地址 |
| `MAP_SHARED` | 改动对内核可见 |
| `MAP_ANONYMOUS` | 不关联文件 |
| `MAP_FIXED_NOREPLACE` | 必须映射到该地址，被占则失败 |

检查：

```cpp
if (req == MAP_FAILED) {
    LS_LOGE_TAG("Driver", "分配共享内存失败: errno=%d (%s)", errno, strerror(errno));
    return;
}
__builtin_memset(req, 0, sizeof(request_obj));
```

## 握手

初始化后要等内核就绪：

```cpp
while (!req->user) {        // 等内核置位
    asm volatile("yield");
}
req->user = false;          // 消费
```

内核启动时把 `user` 置 true，表示"我准备好了"。

> [!danger] 这里会永久阻塞
> 如果没有内核驱动，这个循环永远出不来。
> 这就是本项目"内核模式无驱动时卡死"的原因（第 14 章记录的缺陷之一）。
> **工程上应该加超时**：
> ```cpp
> auto deadline = now + 5s;
> while (!req->user && now < deadline) { yield; }
> if (!req->user) return false;     // 超时失败
> ```

## 分块读写

一次最多传 4096 字节，超过要分块：

```cpp
int HandleVirtualMemoryRWEvent(request_op op, uint64_t addr,
                               void *buffer, size_t size) {
    if (!buffer || size == 0) return -EINVAL;
    if (op != request_op_vmem_read && op != request_op_vmem_write) return -EINVAL;

    std::scoped_lock<SpinLock> lock(m_mutex);      // ★ 加锁
    const bool is_read = (op == request_op_vmem_read);
    size_t processed = 0;
    size_t successfulBytes = 0;
    int lastStatus = -EIO;

    while (processed < size) {
        const size_t chunk = std::min(size - processed,
                                      sizeof(req->vmemrw_info.user_buffer));

        StoreRequestOp(op);
        req->tgid = global_pid;
        req->vmemrw_info.rw_addr = addr + processed;
        req->vmemrw_info.size = chunk;
        StoreRequestStatus(0);

        if (is_read) {
            if (size > 8) __builtin_memset(req->vmemrw_info.user_buffer, 0, chunk);
            else copy_chunk(req->vmemrw_info.user_buffer,
                            (uint8_t*)buffer + processed, chunk);
        } else {
            copy_chunk(req->vmemrw_info.user_buffer,
                       (uint8_t*)buffer + processed, chunk);
        }

        IoCommitAndWait();          // ★ 提交并等待

        const int requestStatus = LoadRequestStatus();
        lastStatus = requestStatus;
        if (requestStatus > 0)
            successfulBytes += std::min((size_t)requestStatus, chunk);

        if (is_read)
            copy_chunk((uint8_t*)buffer + processed,
                       req->vmemrw_info.user_buffer, chunk);

        processed += chunk;
    }

    if (successfulBytes == 0) return lastStatus;
    return successfulBytes > (size_t)INT_MAX ? -EOVERFLOW : (int)successfulBytes;
}
```

## 几个设计细节

### 1. 为什么读小数据时先回填原值

```cpp
if (size > 8) __builtin_memset(req->vmemrw_info.user_buffer, 0, chunk);
else copy_chunk(req->vmemrw_info.user_buffer,
                (uint8_t*)buffer + processed, chunk);
```

小尺寸（≤8 字节）读取时，先把调用方缓冲区**原来的值**填进共享缓冲。
这样如果内核读取失败（没覆盖缓冲），回拷时仍然保持原值。

**意义**：读取失败不会把调用方的数据清零。

### 2. copy_chunk 为什么按大小分支

```cpp
const auto copy_virtual_memory_chunk = [](void *dst, const void *src, size_t n) {
    switch (n) {
    case 1:  __builtin_memcpy(dst, src, 1); break;
    case 2:  __builtin_memcpy(dst, src, 2); break;
    case 4:  __builtin_memcpy(dst, src, 4); break;
    case 8:  __builtin_memcpy(dst, src, 8); break;
    case 16: __builtin_memcpy(dst, src, 16); break;
    default: __builtin_memcpy(dst, src, n); break;
    }
};
```

固定大小的 memcpy 编译器会直接展开成几条 `ldr`/`str` 指令，
不调用 libc。对于 1/2/4/8 字节这种高频场景能省一点开销。

### 3. 为什么全程持有锁

`std::scoped_lock<SpinLock> lock(m_mutex)` 包住整个循环。

因为共享内存**只有一份**——两个线程同时用会互相覆盖请求。

### 4. 返回值语义

| 返回 | 含义 |
|---|---|
| `> 0` | 成功传输的字节数 |
| `-EINVAL` | 参数非法 |
| `-EIO` | 全部失败 |
| `-EOVERFLOW` | 超过 int 范围 |

## 状态字段

```cpp
inline void StoreRequestStatus(int status) { req->status = status; }
inline int  LoadRequestStatus() { return req->status; }
```

内核处理完后设置 `status`：
- `> 0`：实际传输的字节数
- `0` 或负值：错误码

用户态据此判断部分成功。

## 完整的调用流程

```
Read(addr, buf, 10000)
  ↓
chunk = min(10000, 4096) = 4096
  ├─ 写 req->vmemrw_info.rw_addr = addr
  ├─ 写 req->vmemrw_info.size = 4096
  ├─ req->kernel = true
  ├─ 等 req->user
  ├─ 拷回 4096 字节
  ↓
processed = 4096
chunk = min(5904, 4096) = 4096
  ├─ ...同上（addr + 4096）
  ↓
processed = 8192
chunk = min(1808, 4096) = 1808
  ├─ ...同上
  ↓
返回 10000
```

**读 10KB 需要 3 轮请求-响应。**

## 性能推算

| 场景 | 轮数 | 耗时（假设每轮 2µs） |
|---|---|---|
| 读 8 字节 | 1 | ~2 µs |
| 读 4KB | 1 | ~2 µs |
| 读 64KB | 16 | ~32 µs |

对比 `process_vm_readv` 一次读 64KB：~10 µs（受 IOV_MAX 限制可能需要分批）。

**各有胜负**：小数据内核驱动快，大数据两者接近。

## 自己实现一个（用户态双进程版）

第 78 章末尾的简化版，这里补全：

```cpp
// shm_rpc.h
#pragma once
#include <cstdint>
#include <cstddef>

enum class Op : int {
    None = 0,
    Read = 1,
    Write = 2,
    Exit = 99,
};

struct ShmRequest {
    volatile bool   kernel = false;     // 客户端置位
    volatile bool   user   = false;     // 服务端置位
    volatile Op     op     = Op::None;
    volatile int    status = 0;
    int             tgid   = 0;

    uint64_t        addr   = 0;
    int             size   = 0;
    uint8_t         buffer[4096] = {};
};

class ShmClient {
public:
    bool Init();
    void Shutdown();
    int  Read (uint64_t addr, void *buf, int size);
    int  Write(uint64_t addr, const void *buf, int size);
private:
    void CommitAndWait();
    ShmRequest *req_ = nullptr;
    size_t      size_ = 0;
};
```

```cpp
// shm_rpc.cpp（客户端）
#include "shm_rpc.h"
#include <sys/mman.h>
#include <fcntl.h>
#include <unistd.h>
#include <cstring>

#define SHM_NAME "/klbq_rpc_demo"

bool ShmClient::Init() {
    int fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);
    if (fd < 0) return false;
    ftruncate(fd, sizeof(ShmRequest));
    req_ = (ShmRequest*)mmap(nullptr, sizeof(ShmRequest),
                             PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
    close(fd);
    if (req_ == MAP_FAILED) { req_ = nullptr; return false; }

    // 握手：等服务端就绪
    for (int i = 0; i < 500; i++) {          // 5 秒超时
        if (req_->user) { req_->user = false; return true; }
        usleep(10000);
    }
    return false;
}

void ShmClient::CommitAndWait() {
    req_->kernel = true;
    while (!req_->user) { __builtin_ia32_pause(); }   // x86；ARM64 用 asm("yield")
    req_->user = false;
}

int ShmClient::Read(uint64_t addr, void *buf, int size) {
    if (!req_ || size <= 0 || size > 4096) return -1;
    req_->op   = Op::Read;
    req_->addr = addr;
    req_->size = size;
    req_->status = 0;
    CommitAndWait();
    if (req_->status <= 0) return req_->status;
    memcpy(buf, req_->buffer, req_->status);
    return req_->status;
}

int ShmClient::Write(uint64_t addr, const void *buf, int size) {
    if (!req_ || size <= 0 || size > 4096) return -1;
    memcpy(req_->buffer, buf, size);
    req_->op   = Op::Write;
    req_->addr = addr;
    req_->size = size;
    req_->status = 0;
    CommitAndWait();
    return req_->status;
}
```

服务端：

```cpp
// server.cpp
int main(void) {
    int fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);
    ftruncate(fd, sizeof(ShmRequest));
    auto *req = (ShmRequest*)mmap(nullptr, sizeof(ShmRequest),
                                  PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);
    close(fd);

    memset(req, 0, sizeof(*req));
    req->user = true;                 // 通知客户端：我好了
    printf("服务端就绪\n");

    // 模拟"被操作的内存"
    uint8_t fakeMemory[65536];
    for (int i = 0; i < sizeof(fakeMemory); i++) fakeMemory[i] = i & 0xFF;

    while (true) {
        if (!req->kernel) { usleep(50); continue; }    // 让出 CPU

        switch (req->op) {
        case Op::Read:
            if (req->addr + req->size <= sizeof(fakeMemory)) {
                memcpy(req->buffer, fakeMemory + req->addr, req->size);
                req->status = req->size;
            } else {
                req->status = -1;      // 越界
            }
            break;
        case Op::Write:
            if (req->addr + req->size <= sizeof(fakeMemory)) {
                memcpy(fakeMemory + req->addr, req->buffer, req->size);
                req->status = req->size;
            } else {
                req->status = -1;
            }
            break;
        case Op::Exit:
            printf("收到退出指令\n");
            return 0;
        default:
            req->status = -2;
            break;
        }

        req->kernel = false;
        req->user = true;              // 完成
    }
}
```
