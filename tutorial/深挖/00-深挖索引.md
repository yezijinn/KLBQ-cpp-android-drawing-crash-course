## 与正文的关系

```
正文（必读，100 章）
    ├─ 每章：先给可运行结果 → 原理 → 动手 → 坑 → 验收
    └─ 目标：能跟着做出六个成品

深挖（选读，8 篇）
    ├─ 每篇：完整推导 → 边界情况 → 优化 → 工程化
    └─ 目标：能自己改、自己优化、自己推导
```

**建议的读法**：

1. **第一遍**：只读正文，把六个成品做出来
2. **第二遍**：每读完一卷，读对应的深挖
3. **卡住时**：直接跳到深挖的对应小节（比如"遮挡判定全错"→ 深挖 H 第五节）
